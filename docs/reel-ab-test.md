# 릴스 A/B — 자체 템플릿 vs anim-reel

2026-11-18 시작. **감이 아니라 숫자로 고른다.**

## 두 갈래

| | A안 | B안 |
|---|---|---|
| 이름 | 자체 템플릿 | anim-reel |
| 만든 곳 | 이 저장소 (클라우드) | 맥 |
| 규칙 | `tools/reels/NOTES.md` | `tools/reels-anim/NOTES.md` |
| 방식 | HTML `seek(t)` → Playwright 프레임 캡처 → ffmpeg | 미확인 |
| 상태 | 돌아감 | **재현 불가 — 규칙 파일 대기** |

**규칙을 합치지 않는다.** 한쪽이 이길 때까지 두 폴더를 따로 둔다.

## 어떻게 고르나

같은 주제(**김치의 날**)를 두 버전으로 만들어 두었다.
같은 캡션 · 같은 해시태그 · 같은 시간대로 올리고, 이 두 숫자만 본다.

| 지표 | 현재 (A안 1번 게시물) | 목표 |
|---|---|---|
| 평균 조회 시간 | 1초 | **3초** |
| 건너뛰기 비율 | 90.9% | **75% 이하** |

저장률 · 좋아요는 보지 않는다. 평균 조회 시간이 3초를 넘기기 전까지
모수가 없어서 평가 자체가 성립하지 않는다.

## 주의 — 한 번에 하나만 바꾼다

A안도 지금 훅을 고쳐서 다시 재는 중이다.
**A안 훅 수정 결과가 먼저 나온 뒤에** B안을 올린다.
둘을 같은 주에 섞으면 무엇이 효과였는지 알 수 없다.

순서:

1. 11-19 ~ 11-20 — A안 (훅 수정본) 2개. 숫자 확인.
2. 그다음 — B안 김치의 날. 같은 조건으로.
3. 이긴 쪽 규칙만 남기고 다른 쪽 폴더는 접는다.

## 실제로 올라간 것 — 2026-11-19 시점

설계와 달라졌다. **A안 훅 비교는 성립하지 않는다.**

| # | 날짜 | 올라간 것 | 만든 곳 | 훅 |
|---|---|---|---|---|
| 1 | 11-18 | 국어 수업 시간 (정보형) | 클라우드 | "생각보다 적습니다" |
| 2 | 11-19 | NASA 무료 사진 | **맥** | "그냥 써도 될까?" |

1번 숫자: 조회 107 · 평균 조회 시간 **1초** · 건너뛰기 **90.9%**.

### 무엇이 꼬였나

1번의 훅 문제를 고친 클라우드 버전(큰 "0원" 블록, "아이 숙제에 써도 됩니다")을
드라이브에 올려 뒀는데, 2번은 **맥에서 새로 만든 것**이 올라갔다.
훅만 바뀐 게 아니라 **템플릿·색·구성이 전부 다르다.**

→ 2번 숫자가 좋아도 **훅 덕분인지 템플릿 덕분인지 가릴 수 없다.**
드라이브의 `11-19_목_자료_NASA무료사진.mp4`(클라우드판)는 쓰이지 않았다.

### 눈에 띄는 것 하나

2번 훅 "그냥 써도 될까?" 는 **질문형**이다.
anim-reel 의 `references/script-formula.md` 는 질문형 훅을 **하지 말 것**으로 적어 뒀다.
첫 화면 문구만 보고 판단한 것이라 말하는 훅은 다를 수 있다. 확인이 필요하다.

### 다시 세운 설계

**2번의 24시간 숫자를 먼저 본다.** 그걸로 갈림길이 정해진다.

| 2번 결과 | 판단 | 다음 |
|---|---|---|
| 평균 조회 시간 **3초 이상** | 맥 제작본이 먹힌다 | **맥 제작본으로 통일.** A안은 접는다 |
| **1~2초대** | 훅·템플릿 문제가 아니다 | 소재와 타깃을 의심한다. 포맷을 바꾼다 |

맥 제작본으로 통일하면 그림이 맞아떨어진다.
소리가 영상에 들어 있어 **맥에서 업로드할 수 있고**, 인스타 관리도 맥에서 한다.
A안은 소리가 없어 모바일 업로드가 강제된다.

### 앞으로 지킬 것

- **한 번에 하나만 바꾼다.** 훅을 보려면 템플릿을 고정하고, 템플릿을 보려면 훅을 고정한다
- 드라이브에 올려 둔 것과 **다른 걸 올렸으면 그날 안에 알려준다.** 기록이 어긋나면 비교가 무의미해진다
