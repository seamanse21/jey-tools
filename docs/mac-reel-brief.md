# 맥에서 anim-reel 릴스 만들 때 붙여 넣는 글

클라우드 세션은 맥 폴더를 쓸 수 없다(2026-11-19 기준, 계정에 기능이 열려 있지 않음).
그래서 **릴스 제작만 맥에서 하고 나머지는 클라우드에서** 한다.

## 역할 나누기

| 작업 | 어디서 |
|---|---|
| anim-reel 릴스 제작 | **맥** — Claude 데스크톱 앱으로 `~/Claude` 열기 |
| 랜딩페이지 · 깃허브 · 드라이브 · PDF 발행 | 클라우드 |
| 인스타 계정 · 포스팅 판단 · 숫자 분석 | 클라우드 |

주고받기는 **구글 드라이브 `10분 키즈뉴스/01_릴스`** 로 한다.

## 맥 세션에 붙여 넣을 글

아래를 통째로 복사해서 맥 Claude 세션 첫 메시지로 넣는다.
`<주제>` 자리만 바꾼다.

---

```
anim-reel 스킬로 릴스를 만들어줘. 주제는 <주제>.

브랜드는 '10분 키즈뉴스'(@10minkids). 7세~초등 4학년 자녀를 둔
학부모가 보는 계정이야. 아이가 아니라 부모한테 말하는 톤으로.

규칙은 anim-reel 기본값을 그대로 따라줘. 길이도 장면도 CTA 형식도
내가 따로 줄이거나 바꾸라고 하지 않는 한 손대지 마.

지켜줄 것:
- 대본은 references/script-formula.md 공식대로
- 장면은 references/scene-recipes.md 에서 골라 쓰기
- 효과음은 10초에 3~4개
- 캐릭터는 없음. 장면을 500~1650px 에 크게
- 지어낸 숫자·통계 금지. 확인 안 된 건 일반적인 표현으로
- 빌드 후 contact sheet 를 직접 열어 qa-checklist.md 로 검수하고
  빈 화면·글자 잘림을 고친 다음에 보여줘

결과는 ~/Claude/릴스/<이름>/out/final.mp4 로.
다 되면 파일 용량도 알려줘.
```

---

## 맥에서 다 만든 뒤

1. `final.mp4` 가 100MB 넘으면 올리기 불편하니 한 벌 더 뽑는다.

```bash
cd ~/Claude/릴스 && ffmpeg -i <이름>/out/final.mp4 -c:v libx264 -crf 25 -preset medium -pix_fmt yuv420p -c:a copy -movflags +faststart <이름>_올리기용.mp4
```

2. 구글 드라이브 `10분 키즈뉴스/01_릴스` 에 올린다.
   파일 이름은 **올릴 날짜부터** — `11-24_화_종의기원.mp4` 처럼.

3. 클라우드 세션에 "드라이브에 올렸어" 라고만 하면 거기서 이어받는다.

## 올릴 때 (anim-reel 결과물 공통)

- **소리가 영상에 들어 있다.** 인스타 음원을 얹지 않아도 되고 PC 업로드도 된다.
- **프레임 0 이 비어 있다.** `lead` 0.4초 때문이다. **커버를 직접 골라야 한다.**
- AI 목소리를 썼으면 업로드할 때 **"AI 정보" 라벨**을 켠다.
- CTA 가 댓글 키워드면 **댓글에 답을 보내 줘야 말이 된다.**

## 기능이 열렸는지 확인하는 법

클라우드 세션에서 "맥 연결 다시 확인해줘" 라고 하면 된다.
목록에 `not_available` 이 아니라 쓸 수 있는 폴더로 뜨면 그때부터는
클라우드에서 바로 맥을 쓸 수 있다.
