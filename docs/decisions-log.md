**소개글 전문** (2026-11-19 기준)

```
7세–초4 하루 10분, 한 장으로 읽는 뉴스
단어 · 사자성어 · 한자까지 한 번에
인쇄해서 바로 쓰는 PDF
↓ 1주일치 샘플 받기
```

**링크를 바로 건 이유** — "새 계정 + 링크 = 스팸 표식" 은 근거가 약한 통설이고,
링크가 없으면 프로필에 들어온 사람이 할 게 없다는 손실은 확실하다.
확실한 손실을 피하는 쪽을 택했다.

## 2. 스티비 설정값

| 항목 | 값 | 왜 |
|---|---|---|
| 구독 확인 메일 | **끔** | 퍼널을 4단계 → 2단계로 줄이려고. 더블 옵트인을 버린 대신 랜딩에 **오타 가드**를 넣었다 |
| 개인정보 수집·이용 | **(필수)** | 정보통신망법상 수집에 필요 |
| 광고성 정보 수신 | **(선택)** | **필수로 만들면 위법이다.** 한때 필수로 바꾸려다 되돌렸다 |
| 아이 학년 입력란 | **없앰** | 다자녀 가정이면 하나만 고르게 하는 게 말이 안 된다. 입력 단계도 줄었다 |
| 폼 토큰 | `10minkids/index.html` 안에 있음 | 문서에 따로 복사해 두지 않는다 |

**발신자 정보는 아직 한 번도 쓰이지 않았다.**
구독 확인 메일을 껐고 PDF 는 랜딩의 `/thanks/` 에서 바로 주므로,
**우리 리스트에서 나간 메일이 0통이다** (2026-11-19 메일함 확인).

보는 곳: `주소록 → 주소록 설정 → 발신자 정보` (기본값).
이메일을 만들 때 매번 덮어쓸 수도 있다.

**매주 금요일 1장 발송을 시작하기 전까지는 급하지 않다.** 그때 이렇게 맞춘다.

| 항목 | 값 | 왜 |
|---|---|---|
| 발신자 이름 | `10분 키즈뉴스` | 받은메일함에서 브랜드로 보여야 한다 |
| 발신자 이메일 | `hello@10minkids.com` 같은 도메인 주소 | gmail.com 발신은 스팸함 확률이 올라간다 |

> 도메인 메일은 아직 없다. 호스팅케이알에서 **등록만** 한 상태라 메일 기능이 없다.
> 첫 발송 전에 메일 호스팅을 붙여야 한다.

## 3. 가격 — `funnel.md` 에 없는 근거

- **경쟁 제품(리딩타임스)은 PDF 23,000원/월.** 우리 6개월 54,000원은 월 9,000원으로
  **약 2.5배 싸다.** 품질이 아니라 가격으로 비교당하는 자리를 피하려고 일부러 벌렸다.
- **월 결제 상품을 두지 않는다.** 월 9,000원짜리는 두 달이면 해지된다.
  6개월·1년만 둬서 **해지 시점 자체를 없앴다.**
- **무료와 유료를 내용으로 가르지 않는다.** 제작비가 0이라 아낄 이유가 없다.
  **분량으로만 가른다** (무료 주 1장 / 유료 주 6장).
- 1년 상품은 팔려고 두는 게 아니다. **6개월을 싸 보이게 하는 장치다.**

## 5. 사고 기록

### 2026-11-19 — 인스타 본인 확인 (해결됨)

"10minkids님, 프로필을 사용하려면 **사람임을 확인하세요**" + 약 30초.
비활성화·정지가 아니라 **봇 검사**였다. 영상 셀카로 통과.

**짚이는 원인** — 24시간 안에 이게 겹쳤다.
계정 생성 직후 사용자명 변경 → 새 도메인 링크 추가 → PC 웹 업로드 →
삭제 → 모바일 재업로드 → 팔로우 4개.
팔로워 0인 새 계정에서 **자동화 도구로 보이는 패턴**이다.

**이후 2주 제약**
- 업로드는 **모바일 앱에서만**. PC·맥 웹 금지
- **지우고 다시 올리기 금지**
- 하루 1개, 팔로우 하루 5개 이내
- 2단계 인증 켜기

업로드 수단은 콘텐츠에 따라 갈린다.
**A안은 소리가 없어 인스타 음원을 얹어야 하므로 모바일 필수**,
**B안은 소리가 들어 있어 PC·맥 업로드가 된다.**
맥에서 관리하려면 B안으로 통일해야 그림이 맞는다.
