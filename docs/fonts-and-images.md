# 글꼴과 이미지 — 도구별 규칙

맥 세션에 공유하는 문서. **도구마다 규칙이 다르다.**

## 한눈에

| 도구 | 글꼴 | 이미지 |
|---|---|---|
| `kids-weekly.html` (PDF 신문) | **시스템 글꼴만.** 받을 것 없음 | 발행기 안에서 끌어 넣기. 자동 축소 |
| `kids-cards.html` (카드뉴스) | `tools/fonts/` 자체 호스팅 183개 | 호 JSON 의 `photo` 경로 |
| `tools/reels/` (A안 릴스) | 같은 183개를 `_fonts.css` 로 다시 씀 | `photo.jpg` 를 템플릿 옆에 복사 |
| `anim-reel` (맥) | 스킬이 알아서 받음 (Pretendard 등) | `R/assets/` 에 넣고 `<img>` |

---

## 1. PDF 신문 발행기 — 가장 단순하다

**글꼴을 받을 필요가 없다.** `kids-weekly.html` 은 외부 라이브러리·API·네트워크
없이 HTML 한 파일로 돈다. 글꼴도 시스템 글꼴만 쓴다.
→ 맥에서 열든 웹에서 열든 결과가 같다.

**이미지는 발행기 안에서 넣는다.**
- 사진 칸에 파일을 끌어 넣으면 **가로 1200px · JPEG 0.82** 로 줄여서 넣는다
- 브라우저 안(localStorage)에만 저장된다. **외부로 나가지 않는다**
- 한 주치 12쪽이 사진 5장 넣어도 **1MB 안쪽**이다

**호 JSON 에 경로로 박을 때**는 이렇게 쓴다.

```json
"photo": "issues/img/2026-11-23-mon.jpg",
"cap":   "출처 · USAG-Humphreys, CC BY 2.0 (위키미디어 커먼즈)"
```

- 파일은 `tools/issues/img/<날짜>-<요일>.jpg` 또는 `.svg`
- `cap` 은 **반드시** 적는다. 우리가 그린 것이면 `출처 · 10분 키즈뉴스`

### 이미지 출처 정책

| 종류 | 어디서 | 표기 |
|---|---|---|
| 기본 | **AI 일러스트** (우리가 만든 SVG) | `출처 · 10분 키즈뉴스` |
| 역사적 인물·사건 | **공공누리** · 위키미디어 커먼즈 | 원 출처 + 라이선스 |
| 과학·우주 | **NASA** (`images.nasa.gov`, `apod.nasa.gov`) | `출처 · NASA` |

**NASA 조건** (2026-11-18 공식 지침 확인)
- 교육·정보 목적으로 쓸 수 있고 미국에서 저작권 대상이 아니다
- **출처를 NASA 로 밝혀야 한다**
- **로고·휘장·식별자는 쓸 수 없다.** 따로 법으로 보호된다
- 제3자 저작물이 섞인 것은 저작권 표시가 붙어 있다 → 그건 피한다

**남의 화면이나 이미지를 가져다 쓰지 않는다.** 소개는 자유지만 복제는 아니다.

**"AI 일러스트"는 직접 그린 SVG 벡터 그림이다** (2026-11-19 확정).
이미지 생성 모델로 뽑은 래스터 이미지가 아니다. 11/23 주와 11/30 주 모두 이 방식이다.

**NASA 는 우주·천체일 때 먼저 찾는다.** 과학 주제라고 무조건은 아니다.
개념을 그림으로 설명하는 쪽이 나으면(눈 결정의 구조, 흙 단면) **우리 일러스트를 쓴다.**
실제 모습을 보여 주는 것이 중요할 때만 사진을 가져온다.

#### 일러스트 그릴 때
- viewBox `0 -13 480 265` — 기존 파일과 같게. 지면에서 가로로 꽉 차게 들어간다
- 납작한 벡터, 연한 색, 외곽선은 가늘게. 그라데이션은 필요할 때만
- 글자는 되도록 넣지 않는다. 넣어야 하면 숫자처럼 글꼴을 안 타는 것으로
- 파일명 `issues/img/<그 주 월요일>-<요일>.svg` — 요일은 `mon tue wed thu fri`
- **왼쪽 아래 구석을 비워 둔다.** 발행기가 그 자리에 `cap`(출처) 띠를 덮어 그린다.
  대략 가로 0~200 · 세로 215~252 영역. 여기에 글자나 중요한 그림을 두면 가려진다
  (12/07 주 월요일 "남극 · 땅" 라벨이 실제로 가려져 위로 옮겼다, 2026-11-19)

#### 지난 주차 정리 (2026-11-19)
11/23 주의 SVG 세 장은 `cap` 이 옛 이름이라 `출처 · 10분 키즈뉴스` 로 바꿨다.
같은 호의 사진 두 장(월·목)은 위키미디어에서 가져온 것이라 **원저작자와 라이선스 표기를
그대로 둔다.** 그건 우리 이름으로 바꾸면 안 된다.

## 2. 카드뉴스 생성기 — 캔버스 글꼴 함정

`tools/fonts/` 에 **183개 woff2** 를 자체 호스팅한다 (Gowun Dodum, Jua 등 OFL).

### 반드시 알아야 할 것

구글 폰트는 한글을 `unicode-range` 로 100개 가까이 쪼갠다.
브라우저는 **DOM 에 그 글자가 나타날 때** 해당 조각을 받아온다.
캔버스 `fillText` 는 그 신호를 주지 않으므로 **DOM 에 없는 글자는 조용히
시스템 글꼴로 떨어진다.** ("짠" 한 글자만 다른 글꼴로 나온 적이 있다)

```js
// ❌ 이것만으로는 안 된다 — 이미 요청된 폰트만 기다린다
await document.fonts.ready;

// ✅ 그릴 글자를 모두 모아 미리 부른다
await document.fonts.load('400 96px "Jua"', 그릴글자전부);
```

`render()` 앞에서 `preloadFonts()` 를 부른다.
**카드에 새 문구를 넣으면 그 문구도 이 목록에 넣어야 한다.**

### 경로 함정

`fonts.css` 안의 `url(./fonts/...)` 는 **CSS 파일 위치 기준**이다.
`fonts.css` 를 `fonts/` 안으로 옮겼다가 `fonts/fonts/` 를 찾아 전부 404 가
났고, 페이지는 조용히 시스템 글꼴로 떨어졌다. **옮기지 않는다.**

### 규격

카드는 **1080×1350 (4:5)**. 1:1 에서 바꿨다. 피드에서 세로가 더 넓게 잡힌다.

## 3. A안 릴스 — 글꼴을 절대 경로로 바꿔 쓴다

`make-*.js` 가 `tools/fonts/fonts.css` 를 읽어 `./fonts/` 를
`file:///…/tools/fonts/` 절대 경로로 치환한 `_fonts.css` 를 만든다.
헤드리스 크롬이 `file://` 로 열기 때문이다.

**사진**: `photo.jpg` 를 템플릿 옆에 두면 첫 장면 배경으로 쓴다.
`tools/issues/img/` 에서 그날 사진을 복사한다. **커밋하지 않는다.**

**SVG 일러스트는 다르게 다룬다.** 사진처럼 어둡게 깔면 뭉개진다.
`.illu` 모드 — 흰 카드 위에 그림을 얹고 글자는 아래에 둔다.

## 4. anim-reel (맥) — 스킬이 알아서 한다

`RM new` 가 폰트와 효과음을 받는다. 받는 곳은 세 군데다.

| 받는 것 | 어디서 |
|---|---|
| Pretendard (기본 글꼴) | `cdn.jsdelivr.net` |
| 나눔명조 · JetBrains Mono | `fonts.googleapis.com` |
| 효과음 37개 | `assets.mixkit.co` |

맥은 그냥 된다. **클라우드에서는 이 세 호스트를 열어야 한다** (2026-11-18 열어 둠).

**이미지를 넣을 때**는 `R/assets/` 로 복사한 뒤 `<img>` 로 쓴다.
사용자의 원본을 덮어쓰지 않는다. 항상 복사본으로 작업한다.

```
글꼴·이미지 규칙:

- kids-weekly.html(PDF 신문)은 시스템 글꼴만 쓴다. 받을 것 없다.
  사진은 발행기 안에서 끌어 넣으면 가로 1200px JPEG 0.82 로 줄여 들어간다.
  주차 JSON 에 박을 때는 photo 를 "issues/img/<날짜>-<요일>.jpg" 로,
  cap 에 출처를 반드시 적는다. 우리가 그린 것이면 "출처 · 10분 키즈뉴스".

- 이미지는 기본이 우리 AI 일러스트다. 역사 인물·사건은 공공누리나
  위키미디어, 과학·우주는 NASA 를 쓰고 출처를 밝힌다.
  NASA 로고는 못 쓴다. 남의 화면을 복제하지 않는다.

- 카드뉴스·A안 릴스는 tools/fonts/ 의 183개 woff2 를 쓴다.
  캔버스에 그리기 전에 document.fonts.load(spec, 그릴글자) 를 반드시 부른다.
  document.fonts.ready 만으로는 한글이 시스템 글꼴로 떨어진다.
  fonts.css 를 다른 폴더로 옮기지 않는다. 경로가 깨진다.

- anim-reel 은 스킬이 알아서 받는다. 이미지는 R/assets/ 에 복사하고 <img> 로 쓴다.
```
