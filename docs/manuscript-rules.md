# 원고란 무엇이고 어떻게 만드나

맥 세션이 "원고가 없다" 고 할 때 읽는 문서.

## 먼저 — 릴스에는 원고가 필요 없다

| 만드는 것 | 원고 JSON 이 필요한가 | 무엇이 필요한가 |
|---|---|---|
| **PDF 신문 14쪽** | **필요하다** | `tools/issues/<그 주 월요일>.json` |
| **A안 릴스** (자체 템플릿) | **필요하다** | 같은 JSON 에서 자동 생성 |
| **카드뉴스** | **필요하다** | 같은 JSON |
| **anim-reel 릴스** (맥) | **필요 없다** | **주제 한 줄** |

맥에서 anim-reel 로 만들 때는 주제만 있으면 된다.
**원고는 클라우드에서 만든다.** 발행기(`tools/kids-weekly.html`)가 이 저장소에 있고
맥에는 저장소가 없다.

## 원고가 뭔가

**한 주(평일 5일) 분량의 기사와 활동지를 담은 JSON 파일 하나.**
`tools/issues/2026-11-23.json` 처럼 **그 주 월요일 날짜**로 저장한다.

하루치에 들어가는 것:

| 키 | 내용 |
|---|---|
| `cat` | 분류 — 기념일 · 인물 · 사회 · 과학 · 문화 · 마음 중 하나 |
| `kicker` · `head` | 작은 제목 · 큰 제목 |
| `body` | 기사 본문. 네 문단, 950~1,100자 |
| `w` · `m` · `ex` | 오늘의 낱말 · 뜻 · 예문 |
| `quiz` | O/X 세 문장 |
| `fill` | 낱말 넣는 빈칸 문장 |
| `facts` | 곁가지 상식 세 줄 |
| `idiom` | 사자성어 |
| `hanja` | 오늘의 한자 |
| `nums` | 숫자로 보는 뉴스 |
| `eng` | 오늘의 영단어 |
| `searchq` · `oneline` · `togo` | 검색 키워드 · 한 줄 질문 · 마무리 |

## 만드는 법 (클라우드에서)

1. `tools/kids-weekly.html` 을 연다
2. 주 시작일과 날짜별 분류를 정한다
3. **[원고 요청문 복사]** 를 눌러 주문서를 복사한다
4. 클로드에 붙여넣고 받은 JSON 을 **[불러오기]** 한다
5. `tools/issues/<월요일>.json` 으로 저장하고 PDF 를 뽑는다

요청문 전문은 `tools/kids-weekly.html` 의 `promptText()` 함수에 있다.
버튼으로 복사하는 게 정확하니 손으로 옮겨 적지 않는다.

## 원고를 쓸 때 꼭 지키는 것

발행기 요청문에 들어 있는 규칙 중 **틀리기 쉬운 것들**.

- **숫자와 연도는 확실한 것만.** 모르면 쓰지 않는다
- **사자성어 난이도** — 고사를 몰라도 글자 뜻만 합쳐 이해되는 것만.
  쓸 수 있는 것: 동고동락 · 작심삼일 · 일석이조 · 십중팔구 · 동문서답 · 유비무환 ·
  상부상조 · 소탐대실 · 자업자득 · 다다익선 · 이구동성 · 백발백중 · 삼삼오오 ·
  역지사지 · 금상첨화
  쓰지 않는 것: 우공이산 · 결초보은 · 과유불급 · 토사구팽 · 새옹지마 · 청출어람
  (실제 학부모 피드백으로 정해진 기준이다)
- **한자는 8급~5급**, 한국어문회 기준. 기사 주제를 바로 가리키는 글자로.
  사자성어에서 한 글자를 떼어 오지 않는다
- **O/X 세 문장은 기사의 서로 다른 문단에서.** 적어도 하나는 X.
  상식만으로 맞힐 수 있는 문장은 쓰지 않는다
- **영단어는 오늘의 낱말과 짝**이 되게. 예문은 여섯 단어 이내
- **쓰는 분량은 적게, 읽는 재미는 크게**
