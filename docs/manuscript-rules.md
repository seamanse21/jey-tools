# 원고란 무엇이고 어떻게 만드나

맥 세션이 "원고가 없다" 고 할 때 읽는 문서.

## 먼저 — 릴스에는 원고가 필요 없다

| 만드는 것 | 원고 JSON 이 필요한가 | 무엇이 필요한가 |
|---|---|---|
| **PDF 신문 14쪽** | **필요하다** | `tools/issues/<그 주 월요일>.json` |
| **A안 릴스** (자체 템플릿) | **필요하다** | 같은 JSON 에서 자동 생성 |
| **카드뉴스** | **필요하다** | 같은 JSON |
| **anim-reel 릴스** (맥) | **필요 없다** | **주제 한 줄** |

맥에서 anim-reel 로 만들 때는 주제만 있으면 된다.
**원고는 클라우드에서 만든다.** 발행기(`tools/kids-weekly.html`)가 이 저장소에 있고
맥에는 저장소가 없다.

## 원고가 뭔가

**한 주(평일 5일) 분량의 기사와 활동지를 담은 JSON 파일 하나.**
`tools/issues/2026-11-23.json` 처럼 **그 주 월요일 날짜**로 저장한다.

하루치에 들어가는 것:

| 키 | 내용 |
|---|---|
| `cat` | 분류 — 기념일 · 인물 · 사회 · 과학 · 문화 · 마음 중 하나 |
| `kicker` · `head` | 작은 제목 · 큰 제목 |
| `body` | 기사 본문. 분량은 글자 수가 아니라 **폰트 크기**로 맞춘다 (아래) |
| `w` · `m` · `ex` | 오늘의 낱말 · 뜻 · 예문 |
| `quiz` | O/X 세 문장 |
| `fill` | 낱말 넣는 빈칸 문장 |
| `facts` | 곁가지 상식 세 줄 |
| `idiom` | 사자성어 |
| `hanja` | 오늘의 한자 |
| `nums` | 숫자로 보는 뉴스 |
| `eng` | 오늘의 영단어 |
| `searchq` · `oneline` · `togo` | 검색 키워드 · 한 줄 질문 · 마무리 |

## 만드는 법 (클라우드에서)

1. `tools/kids-weekly.html` 을 연다
2. 주 시작일과 날짜별 분류를 정한다
3. **[원고 요청문 복사]** 를 눌러 주문서를 복사한다
4. 클로드에 붙여넣고 받은 JSON 을 **[불러오기]** 한다
5. `tools/issues/<월요일>.json` 으로 저장하고 PDF 를 뽑는다

요청문 전문은 `tools/kids-weekly.html` 의 `promptText()` 함수에 있다.
버튼으로 복사하는 게 정확하니 손으로 옮겨 적지 않는다.

## 원고를 쓸 때 꼭 지키는 것

발행기 요청문에 들어 있는 규칙 중 **틀리기 쉬운 것들**.

- **숫자와 연도는 확실한 것만.** 모르면 쓰지 않는다
- **사자성어 난이도** — 고사를 몰라도 글자 뜻만 합쳐 이해되는 것만. 이 기준은 그대로다.
  쓰기 좋은 것: 동고동락 · 작심삼일 · 일석이조 · 십중팔구 · 동문서답 · 유비무환 ·
  상부상조 · 소탐대실 · 자업자득 · 다다익선 · 이구동성 · 백발백중 · 삼삼오오 ·
  역지사지 · 금상첨화
  쓰지 않는 것: 우공이산 · 결초보은 · 과유불급 · 토사구팽 · 새옹지마 · 청출어람
  (실제 학부모 피드백으로 정해진 기준이다)

  **고르는 순서** (2026-11-19 추가)
  1. **한 달에 같은 사자성어를 두 번 쓰지 않는다.** 달이 바뀌면 다시 쓸 수 있다
  2. 기사 내용과 맞물리는 것을 먼저 찾는다
  3. 내용에 맞는 것이 없거나, 그것을 **이번 달에 이미 썼거나 쓸 예정이면**
     내용과 상관없이 **한자 급수 8~6급 글자로만 이루어진 사자성어**를 쓴다

  3번으로 쓸 수 있는 것 (네 글자 모두 8~6급)
  ```
  東問西答 동문서답   三三五五 삼삼오오   百發百中 백발백중   四方八方 사방팔방
  春夏秋冬 춘하추동   男女老少 남녀노소   東西南北 동서남북   青天白日 청천백일
  自問自答 자문자답   山川草木 산천초목   不老長生 불로장생   一長一短 일장일단
  一心同體 일심동체   白面書生 백면서생   一日三秋 일일삼추
  ```
  > 여기서 "만든다"는 **그 급수 글자로 이루어진 실재하는 사자성어를 고른다**는 뜻으로 읽었다.
  > 없는 말을 새로 지어내면 아이가 가짜 사자성어를 외우게 되고, 파는 물건에 들어가는
  > 사실 오류가 된다. 지어내는 쪽을 원하셨다면 알려 주세요.
- **한자는 8급~5급**, 한국어문회 기준. 기사 주제를 바로 가리키는 글자로.
  사자성어에서 한 글자를 떼어 오지 않는다
- **O/X 세 문장은 기사의 서로 다른 문단에서.** 적어도 하나는 X.
  상식만으로 맞힐 수 있는 문장은 쓰지 않는다
- **영단어는 오늘의 낱말과 짝**이 되게. 예문은 여섯 단어 이내
- **쓰는 분량은 적게, 읽는 재미는 크게**

## 본문 분량은 글자 수가 아니라 폰트 크기로 맞춘다

**기준은 본문 10.5~11pt다** (`docs/kids-paper-strategy.md` §3). 글자 수가 아니다.

발행기의 `autoFit()` 은 **넘치지 않는 선에서 가장 큰 크기**를 고른다. 그래서

| 상태 | 뜻 | 할 일 |
|---|---|---|
| 11pt 보다 **크게** 나온다 | 본문이 **모자란다** | 본문을 늘리거나 `nums` 줄을 더한다 |
| 10.5pt 보다 **작게** 나온다 | 본문이 **넘친다** | 본문을 줄이거나 `nums` 줄을 뺀다 |

같은 글자 수라도 `nums` 가 한 줄이냐 세 줄이냐에 따라 한두 단계가 움직인다.
사진·곁가지 상식이 차지하는 높이도 영향을 준다. 그래서 **쓰고 나서 반드시 재 본다.**

```
python3 tools/measure-fs.py 2026-12-07        # 한 주
python3 tools/measure-fs.py --all             # 전부
```

주마다 기사별로 글자 수·실제 폰트·판정을 찍어 준다.
**기준을 벗어난 기사가 0개가 될 때까지 고친다.**

실측해 보면 **790~930자**에서 10.6~11.0pt 가 나온다 (2026-11-19, 11/23~12/28 여섯 주 30편 기준).
발행기 요청문(`promptText()`)의 950~1,100자는 이 기준과 맞지 않으므로 **폰트 쪽을 따른다.**
환불 사유가 되는 것은 글자 수가 아니라 읽기 힘든 지면이기 때문이다.

## 주말 복습 면은 원고에 적지 않는다

주간 PDF 14쪽 = 표지 1 + 사용 안내 1 + 평일 5일 × 2(기사면·활동지면) + **주말 복습 1** + 어휘 모아보기 1.

**13쪽 「주말에 한 번 더」와 14쪽 「한 주 어휘 모아보기」는 발행기가 평일 5일 데이터로 자동으로 만든다.**
원고 JSON 에 따로 쓰는 항목이 없다. 기사 제목 · 낱말 뜻 · 한자 · 영단어 · 사자성어를 끌어다
되짚기, 낱말 채우기, 한자·영단어 쓰기 칸으로 바꿔 놓는다.
그러니 **낱말 뜻(`m`)과 한자·영단어를 대충 쓰면 주말 면이 같이 허술해진다.**

**주의** — 이 표는 주제일 뿐이고 **사실 확인이 안 된 상태다.**
원고를 쓸 때 날짜·연도·숫자를 다시 확인한다. 확실하지 않으면 그 주제를 버리고 바꾼다.

> 12월 표는 **원고를 쓰면서 고친 뒤의 모습이다** (2026-11-19).
> 바뀐 까닭 — ① **2026년 동지는 12월 22일(화)**이다(UTC 12/21 20:50 → KST 12/22 05:50).
> 원래 표의 월요일 동지는 날짜가 틀렸고, 월 "동지와 팥죽"과 화 "하루가 가장 짧은 날"은
> 같은 주제라 하나로 합쳤다. ② **12/25 성탄절은 금요일**이라 목요일에서 옮겼다.
> ③ 12/14 수요일 "산타 이야기의 유래" 와 12/21 수요일 "크리스마스카드의 시작" 을 맞바꿔
> 성탄절에 가까운 주에 산타·캐럴이 오도록 했다. ④ 12/28 금요일은 **2027-01-01** 이라
> 신정으로 채웠고, 목요일은 2027년 예고 대신 해돋이 기사로 바꿨다.
