# 랜딩 페이지 전략 — lazyowen.com 분석과 우리 적용안

작성 2026-11-17 · 분석 대상 https://lazyowen.com / /guides/manyfast-plan-to-claude-code-mockup

## 1. lazyowen 은 어떻게 돌아가는가

3단 퍼널이다.

```
릴스·유튜브 (팔로워 16.1만, 누적 1,165만 조회)
        ↓  프로필 링크 / 댓글 "링크 보냈어요"
사이트 = 무료 가이드 라이브러리
        ↓  이메일 게이트
이메일 리스트
        ↓  사전 등록 → 얼리버드 할인
유료 상품 「30일 AI 챌린지」
```

사이트 자체는 상품을 팔지 않는다. **콘텐츠로 이메일을 모으는 깔때기**이고, 판매는 그 뒤에 온다.
가이드 6편이 전부 "릴스에서 댓글로 요청받은 자료"다. 즉 릴스 → 댓글 → 가이드 → 이메일이 한 줄로 이어진다.

## 2. 이메일 게이트의 실제 작동 방식

**화면**: 가이드 글의 1번 섹션만 보여주고, 2~4번 섹션은 흐리게 처리한다.
왼쪽 목차에는 2·3·4번에 자물쇠 아이콘이 붙고 "잠긴 단계는 이메일 등록 후 열립니다"가 적혀 있다.

**기술**: 잠긴 본문도 HTML 안에 이미 다 들어 있다. 해제는 서버가 아니라 브라우저가 한다.

- 폼 전송 → `POST https://lazyowen.com/api/subscribe` (자체 서버, 외부 메일 서비스 아님)
- 성공하면 `localStorage["lz.guides.unlocked"] = "1"` + 쿠키 `lz_guides_unlocked` 저장
- 그 뒤로는 **사이트의 모든 가이드가 한꺼번에 열린다**
- 봇 방지는 숨은 허니팟 입력칸 `lz_extra`, 메인 폼에는 Cloudflare Turnstile

→ 기술적 자물쇠가 아니라 **심리적 문턱**이다. 개발자 도구를 열면 우회되지만 아무도 그러지 않는다.
마찰이 거의 없으니(이메일 한 칸, 버튼 하나) 전환율이 높다. 이 설계가 핵심이다.

**카피 구조** (그대로 베낄 가치가 있는 부분)

| 자리 | 문구 | 역할 |
|---|---|---|
| 제목 | "이메일 하나면, 전부 무료입니다." | 대가가 작다는 선언 |
| 본문 | "남은 3개 섹션과 이 사이트의 모든 가이드를 무료로 열람하고, 인쇄용 PDF로도 받을 수 있어요" | 받는 것을 숫자로 명시 |
| 가치 | "300만원 상당의 문서와 프롬프트" | 가격 앵커 |
| 신뢰 | "12.7만+ 명이 이 가이드가 나온 채널을 팔로우합니다" | 사회적 증거 |
| 불안 해소 | "스팸 없이 … 언제든 한 번의 클릭으로 취소" | 이탈 방지 |
| 글 머리 | "읽는 데 2분 · 섹션 4개" | 부담 낮추기 |

**법적 처리** (한국 정보통신망법 — 우리도 반드시 따라야 함)

- (필수) 개인정보 수집·이용 동의 — 수집 항목·목적·보관 기간 명시, 개인정보 처리방침 링크
- (필수) 광고성 정보 수신 동의 — **별도 체크박스**로 분리
- "메일 하단에서 언제든 수신을 거부할 수 있습니다" 고지

## 3. 우리에게 맞는가 — 맞다, 단 한 군데를 바꿔야 한다

lazyowen 의 상품은 **정보**라서 글 일부를 보여주고 나머지를 가릴 수 있다.
우리 상품은 **PDF 파일**이다. 가릴 '나머지 본문'이 없다.

그래서 블러 게이트가 아니라 **쇼윈도 게이트**로 바꾼다.

```
랜딩 상단   월요일 1장을 이미지로 통째로 공개 (실물 그대로, 확대 가능)
            → 품질을 눈으로 확인시킨다. 이게 가장 강한 설득이다
중간        화~금 4장 + 주말 복습 1장은 썸네일만 흐리게
            "나머지 5장은 인쇄용 PDF로 보내드려요"
게이트      이메일 한 칸 + 동의 체크 2개 + 버튼
그 뒤       확인 메일에 PDF 다운로드 링크
```

가리는 대상이 '읽을 내용'이 아니라 **'인쇄할 파일'**이기 때문에, 품질을 다 보여줘도 미끼가 죽지 않는다.
오히려 학부모는 사기 않을까 경계하므로 **먼저 다 보여주는 쪽이 유리**하다.

## 4. 미끼 운영 원칙 (이전 결론 유지)

- 무료 배포는 **1주치 1회**. 매주 뿌리면 유료 6개월 구독을 스스로 잠식한다
- 구독자에게는 이후 **월 1회 맛보기 1장**만 보낸다 (리스트 생존용)
- 유료 전환 메일은 구독 3일 뒤, 7일 뒤 2통. 그 이상은 피로

## 5. 우리 조건에서의 차이 — 솔직한 경고

| 항목 | lazyowen | 우리 |
|---|---|---|
| 시작 유입 | 팔로워 16.1만 | 0 |
| 타깃 | AI·개발 관심층 (이메일 친숙) | 7세~초4 학부모 (카톡 선호) |
| 상품 가격대 | 고가 챌린지 | 월 1만원대 구독 |

**랜딩 페이지만 만들면 방문자가 0명이다.** 이 사람의 사이트가 작동하는 이유는 릴스가 100만 뷰를 찍기 때문이지
사이트가 잘 만들어져서가 아니다. 순서는 인스타 콘텐츠 → 그 다음 랜딩이다.

그리고 학부모 타깃은 이메일 열람률이 낮다. **카카오 채널을 이메일과 나란히 두는 것**을 권한다.
(카톡 발송 자동화는 이미 돌리고 있으니 추가 비용이 거의 없다)

## 6. 구현안

lazyowen 은 자체 서버(`/api/subscribe`)를 돌린다. 우리는 서버 없이 가야 한다.

| 안 | 방식 | 비용 | 판단 |
|---|---|---|---|
| **A (권장)** | 랜딩은 GitHub Pages 정적 HTML, 폼만 **스티비** 임베드 | 무료 (구독자 2,000명까지) | 국내 서비스라 수신동의 양식·수신거부·(광고) 표기가 기본 제공. 가장 빠르고 법적으로 안전 |
| B | 구글 폼 → 스프레드시트 → 수동 발송 | 무료 | 자동 발송이 없어 손이 많이 간다. 초기 20명까지만 버틴다 |
| C | 자체 서버 + DB | 유료 | 지금 단계에서 과하다 |

**A안 구성**

```
GitHub Pages  landing/index.html   정적 랜딩 (우리 디자인, Jua + 고운돋움 그대로)
   ├─ 월요일 1장 이미지 공개
   ├─ 나머지 5장 흐린 썸네일
   └─ 스티비 구독 폼 임베드 (동의 체크 2개 포함)
스티비        구독 → 자동 응답 메일 → PDF 다운로드 링크
PDF 호스팅    GitHub 저장소의 release 파일 또는 구글 드라이브 공유 링크
```
