# 어린이 신문 PDF — 제품 전략

작성 2026-11-16. 수익화를 전제로 한 제품 설계 문서. 도구 구현 메모는 `tools/kids-weekly.NOTES.md`.

## 1. 누가 사는가

**구매자는 학부모, 사용자는 아이.** 둘을 같이 만족시켜야 한다.

| | 구매자 (학부모) | 사용자 (7세~초4) |
|---|---|---|
| 원하는 것 | 문해력, 상식, 스스로 읽는 습관 | 재미, 짧음, 만만함 |
| 싫어하는 것 | 시킬 거리가 또 늘어나는 것 | 글 많은 것, 길게 써야 하는 것 |
| 사는 이유 | "하루 10분이면 된다" | (선택권 없음) |
| 그만두는 이유 | 아이가 안 펼친다 | 어렵고 지루하다 |

**이탈의 90%는 아이가 안 펼쳐서 생긴다.** 그래서 지면은 아이 기준으로 설계하고,
학부모에게는 "오늘 무엇을 배웠는지"가 한눈에 보이게 만든다.

## 1-2. 경쟁 제품 (리딩타임스 「하루 한 장 키즈신문」)

상세페이지에서 확인한 것. 우리가 넘어야 할 기준선이다.

| 항목 | 경쟁 제품 |
|---|---|
| 가격 | 종이 25,000원 · **PDF 23,000원** (한 달, 평일 20일치) |
| 발송 | 매월 25~28일에 다음 달분 |
| 타겟 | 7세 ~ 초등 4학년 |
| 핵심 카피 | "읽기 능력이 곧 공부머리" · "하루 10분" · "읽는 습관" |
| 설득 구조 | 문제를 못 읽어서 틀린다 → 모든 과목이 읽기에서 갈린다 → 읽는 습관부터 |
| 부가물 | Parents Guide(학년별 활용법 + 아이와 나눌 대화 주제 추천), ISSN 등록 |
| 신뢰 장치 | 후기 평점 5.0, 카카오톡 채널 문의, 수령 개월수 차감 후 환불 규정 명시 |

**우리가 다르게 가져갈 것**

1. **매일 어휘 세 가지** — 낱말 + 사자성어 + 한자(급수·획수·따라쓰기). 경쟁 제품은 낱말 하나뿐이다.
   한 달이면 60개, 6개월이면 360개. 숫자로 증명되는 차이다.
2. **날짜와 맞아떨어지는 기사** — 그날의 기념일·절기·역사를 그 날짜에 싣는다.
3. **쓰기 부담을 덜어낸 활동지** — 서술형 대신 O/X·빈칸·곁가지 상식. 아이가 스스로 펼치게 만든다.
4. **읽기 습관 추적** — 지면마다 별점·읽은 시간·읽은 방식 체크 칸. 학부모가 성과를 눈으로 본다.
5. **PDF 전용** — 인쇄·우편 비용이 없으니 같은 값에 더 주거나, 6개월 묶음으로 단가를 낮출 수 있다.

### 가격 제안 (결정 전)
경쟁 PDF가 월 23,000원이다. 6개월 선결제를 기본 상품으로 두고 월 단가를 그 아래로 잡되,
"낱말 120 · 사자성어 120 · 한자 120자"를 전면에 세우면 같은 값에서도 더 받는 느낌을 만들 수 있다.

## 2. 우리가 파는 것

> **하루 10분, 한 장 읽고 한 장 푸는 어린이 신문.**
> 날짜에 맞는 이야기로 상식을 쌓고, 매일 어휘 세 가지를 가져갑니다.

제호 기본값은 **「10분 키즈뉴스」** (영문 보조 WEEKLY READING). 발행기 설정에서 바꿀 수 있다.

세 가지 약속을 지면으로 증명한다.

1. **오늘과 맞아떨어진다** — 그날의 기념일·절기·역사적인 날을 그 날짜에 싣는다.
   달력과 신문이 붙어 있으면 "오늘 것"이 되고, 오늘 것은 미루기 어렵다.
2. **매일 같은 자리에서 같은 것을 가져간다** — 오늘의 낱말 / 오늘의 사자성어 / 오늘의 한자.
   학부모가 성과를 셀 수 있고, 아이는 다음 장을 예측할 수 있다.
3. **쓰는 양은 적고, 읽는 재미는 크다** — 서술형 대신 O/X, 빈칸, 곁가지 상식.

### 한 달이면 남는 것
낱말 20개 · 사자성어 20개 · 한자 20자 · 기사 20편.
이 숫자가 상세페이지의 핵심 카피가 된다.

## 3. 상품 구성

| 상품 | 내용 | 전달 |
|---|---|---|
| 무료 샘플 | 1주 = 평일 5일치 (12쪽) | 즉시 다운로드, 이메일 수집 |
| 정기 구독 | 6개월 = 매달 1회 PDF | 매월 말 다음 달분 전송 |

- 한 달 = **평일 20일치**. 표지 + 보호자 안내 + (기사면 + 활동지면) × 20 = **42쪽**
- 주말·공휴일은 쉬고, 그 주의 기념일은 평일 중 가까운 날에 배치한다
- PDF 한 권 1.5~3MB 수준 — 메일·카톡 전송에 문제없는 크기로 유지한다
- 태블릿으로 봐도 글자가 읽히도록 본문 10.5~11pt, 한 쪽에 두 단
  → **이 기준이 글자 수보다 우선한다.** 발행기가 자동으로 정한 크기를
  `python3 tools/measure-fs.py --all` 로 재서 전부 이 범위 안인지 확인한다.
  고치는 방향은 `docs/manuscript-rules.md` 참고 (크게 나오면 본문이 모자란 것이다)

### 가격 설계 메모 (결정 전)
월 단가 × 6개월 선결제. 경쟁 제품이 월 1만원 안팎이므로 그 선에서 잡되,
"낱말 120개 + 사자성어 120개 + 한자 120자"로 환산해 보여 주는 쪽이 설득력이 높다.

## 4. 지면 설계

### 기사면 (왼쪽 장)
- 제호 배너 + 그날 날짜 + 분류 뱃지(분류마다 고유 색)
- 사진/그림 자리 → 부제 → 제목 → 2단 본문 900~1,100자
- 오른쪽: **오늘의 낱말**(뜻 + 손글씨 예문) / 같이 해보자 / **오늘의 읽기**(별점·읽은 시간·읽은 방식 체크)
- 아래: 처음 본 낱말 적는 줄

### 활동지면 (오른쪽 장)
1. **맞혀 보기** — O/X 세 문항, 동그라미만 치면 된다
2. **오늘의 사자성어** — 한자 넉 자 + 독음 + 뜻 + 쓰임새 한 줄
3. **오늘의 한자** — 큰 글자 + 훈음 + 급수·획수 + **따라 쓰는 칸** (8급~5급, 한국어문회 기준)
4. **낱말 채우기** — 오늘의 낱말 빈칸 한 문장
5. **더 알아보기** — 기사에 안 나온 곁가지 상식 두세 개
6. (선택) 한 줄 쓰기 / 그리기
- 정답은 지면 맨 아래 **거꾸로** 인쇄 — 돌려 보는 재미

### 타이포·여백 (A4 기준)
- 판형 210 × 297mm, 바깥 여백 9~11mm
- 본문 10.2~11pt / 행간 1.72 / 두 단, 단 간격 5.5mm
- 기사 제목 23pt, 부제 14pt, 코너 제목 11.5pt
- 기사 길이가 들쭉날쭉해도 **기사별로 글자 크기를 자동으로 맞춰** 한 쪽에 꽉 채운다

### 색
7세도 보는 지면이므로 흑백 신문 톤을 버리고 분류마다 색을 준다.

| 분류 | 색 | | 분류 | 색 |
|---|---|---|---|---|
| 기념일 | 주황 | | 과학 | 청록 |
| 인물 | 보라 | | 문화 | 분홍 |
| 사회 | 파랑 | | 마음 | 노랑 |
| 정치 | 남색 | | 경제 | 초록 |

제호와 코너 머리는 둥근 모서리, 굵은 획, 큰 글자. 선은 가늘게, 면은 넓게.

## 5. 만드는 흐름

1. 매주 금요일 저녁, 예약 작업이 다음 주 5일치를 만들어 저장소에 JSON으로 커밋
2. 발행기(`tools/kids-weekly.html`)에서 불러와 A4로 출력 → PDF
3. 한 달분이 모이면 이어 붙여 월간 PDF로 묶는다

**파일을 가르는 기준이 둘로 다르다** (2026-11-19 확정)

| 산출물 | 범위 |
|---|---|
| 주간 (원고 JSON · 1주치 PDF) | **월요일~금요일.** 달이 바뀌어도 한 주는 한 파일 (예: 11/30~12/4) |
| 월간 (판매용 한달치) | **그 달 1일~말일.** 주 경계와 상관없다 |

### 가리키는 이름은 날짜로 통일한다

**「제1호」「2호」 같은 호수 표기를 쓰지 않는다.** 밀리면 호수가 꼬이기 때문이다
(`docs/decisions-log.md` §4). 화면·문서·파일 이름·대화에서 모두 날짜로 가리킨다.

| 무엇 | 이렇게 쓴다 | 쓰지 않는다 |
|---|---|---|
| 한 주 | `11/23 주` · `11월 23일 ~ 11월 27일` · `2026-11-23` | ~~제1호~~ |
| 한 달 | `2026년 12월분` · `12월 한달치` | ~~12월호~~ |
| 주간 파일 | `261123_261127_10min_kidsnews_weekly.pdf` | |
| 낱장 파일 | `261123_10min_kidsnews_daily.pdf` | |
| 월간 파일 | `261201_261231_10min_kidsnews_monthly.pdf` | |

원고 JSON 과 `index.json` 에도 `issue` 번호를 두지 않는다. 주차 날짜가 곧 이름이다.
(2026-11-20 에 발행기·받는 페이지·원고 여섯 주·문서에서 모두 걷어냈다.)

월간은 주차별 신문을 이어 붙여 만들되 **양면 인쇄를 기준으로 짠다** (2026-11-20).

| 묶음 | 쪽수 | 종이 |
|---|---|---|
| 월간 표지 + 보호자 안내 | 2 | 한 장 앞뒤 |
| 기사면 + 활동지면 (하루치) | 2 | 한 장 앞뒤 |
| 주말에 한 번 더 + 한 주 어휘 모아보기 | 2 | 한 장 앞뒤 |

모든 묶음이 짝수라 **기사면이 언제나 홀수 쪽에 떨어진다.** 그래서 한 장만 뽑으면
앞면이 기사, 뒷면이 그날 활동지가 된다. 보호자 안내에 '긴 쪽 넘김' 안내를 넣는다.

**주차 표지는 넣지 않는다.** 한 달치에서 주마다 차례를 또 두면 쪽수만 늘고,
홀수 한 장이 끼어들어 기사면이 짝수 쪽으로 밀린다. 그러면 기사면과 활동지면이
서로 다른 종이에 찍혀 양면 인쇄가 쓸모없어진다. 차례는 **월간 표지 한 장**이 맡는다 —
그 달 평일을 `날짜 (요일) · 기사 제목` 으로 전부 적는다 (20일 남짓이라 한 쪽에 들어간다).
보호자 안내의 「이번 주 기사」 표는 첫 주 5일만 담겨 오해를 주므로 월간에서는 뺀다.

**그 달 밖 날짜는 뺀다.** 기사면·활동지면만이 아니라 월간 표지 차례의 그 줄,
주말 복습의 그 칸, 한 주 어휘의 표 한 줄·도장판 한 칸·사자성어 짝 한 쌍까지 함께 뺀다.
사지 않은 날을 복습하라고 하면 안 되기 때문이다.

맥에서는 `운영/make-month.py <YYYY-MM>` 한 줄로 만든다 (허브 폴더에 있다).
2026년 12월은 11/30(월)과 2027-01-01(금)이 빠져 **평일 23일분 58쪽**이 되었다.

그래서 12월 판매용에는 11/30 주차의 12/1~12/4 와 12/28 주차의 12/28~12/31 이 들어가고,
11/30 과 2027-01-01 은 빠진다.
4. 무료 샘플은 가장 최근 한 주를 그대로 쓴다

## 6. 품질 기준 (지키지 않으면 환불 사유가 된다)

- 숫자와 연도는 확인된 것만 쓴다. 애매하면 숫자를 뺀다
- 정치·경제는 특정 정당·인물·기업의 입장이 아니라 제도와 개념만 다룬다
- 전쟁·범죄·재해는 자극적인 묘사 없이, 왜 그런 일이 생겼는지까지만
- 한자 급수는 한국어문회 배정 기준을 따르고, 급수와 획수를 함께 적는다
- 저작권: 기사·삽화·캐릭터·제호를 모두 자체 제작한다. 타사 지면을 베끼지 않는다
