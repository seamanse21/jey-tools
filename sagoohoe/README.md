# 사구회 관리 사이트

초등학교 49회 졸업생 9명의 친목 모임 「사구회」를 관리하는 사이트.
**나스 폴더에 그대로 올려 두면 바로 돌아간다.** 외부 서비스·라이브러리를 쓰지 않는다.

메뉴는 네 개다.

| 메뉴 | 하는 일 |
|---|---|
| 회비 현황 | 2006년부터 연도를 골라, 9명 × 12개월 납입 현황을 한 표로 본다 |
| 히스토리 | 연도별 모임 장소·참석자·사진, 그리고 안건별 참석자 투표와 가결 여부 |
| 정산금 신청 | 모임에서 각자 쓴 실비 청구 (기차·비행기·버스·자차, 식사·음료) |
| 회칙 | 현행 회칙과 개정 이력. 옛 버전 보기·되돌리기 |

## 1. 나스에 올리기

### Synology (DSM) 기준

1. **File Station** 에서 `web` 공유 폴더(없으면 패키지 센터에서 **Web Station** 설치) 안에
   `sagoohoe` 폴더를 만든다.
2. 이 폴더의 모든 파일을 그 안에 올린다. (`index.html`, `api.php`, `assets/`, `data/`, `photos/`, `receipts/`)
3. **Web Station → 스크립트 언어 설정**에서 PHP 를 켠다. (기본으로 켜져 있는 경우가 많다)
4. 브라우저에서 `http://나스주소/sagoohoe/` 로 접속한다.

접속했을 때 오른쪽 위에 **「나스 저장」** 이라고 보이면 제대로 된 것이다.
**「이 브라우저에만 저장」** 이라고 나오면 PHP 가 꺼져 있거나 `api.php` 가 안 열리는 상태다.
그 상태로도 쓸 수는 있지만, 자료가 그 브라우저 안에만 남으니 PHP 를 켜는 쪽이 맞다.

### 폴더 권한

`data/`, `photos/`, `receipts/` 세 폴더는 **쓰기 권한**이 있어야 한다.
File Station 에서 폴더 우클릭 → 속성 → 권한에서 `http` 사용자(또는 everyone)에게 읽기/쓰기를 준다.

### 밖에서도 보려면

- 집 안에서만 쓸 거면 나스 내부 주소로 충분하다.
- 밖에서 보려면 Synology **QuickConnect** 나 DDNS + 역방향 프록시를 쓴다.
- 영수증·회비 기록이 들어 있으니 **공개 주소로 열어 두지 말고** DSM 로그인이나
  Web Station 의 접근 제어를 걸어 두는 것이 좋다.

## 2. 처음 할 일

1. **설정** 메뉴에서 회원 명단을 확인한다. (9명이 미리 들어 있다)
2. **설정 → 정산 기준**에서 유류비 단가를 요즘 기름값으로 맞춘다. 연비 기준은 회칙대로 10km/L.
3. **회칙** 메뉴를 열어 초안을 실제 회칙 내용으로 고친다.
   금액이 `○○○,○○○원` 으로 비어 있는 곳과 `※ … 수정하세요` 라고 적힌 곳이 고칠 자리다.
   다 고쳤으면 **편집 → 개정 확정**을 눌러 그 시점 전문을 이력에 남긴다.
4. **회비 현황**에서 연도를 고르고 칸을 눌러 과거 납입 기록을 채운다.

## 3. 쓰는 법 요약

### 회비 현황
- 칸 **클릭** → 그 달 납입 처리 / 다시 누르면 취소
- 칸 **더블클릭(또는 꾹 누르기)** → 금액을 직접 입력 (일부만 냈을 때)
- **월 이름 클릭** → 그 달 9명 전원 납입 처리
- **이름 클릭** → 그 사람 12개월 전체 납입 처리
- `미납 현황 복사` → 카카오톡에 붙여 넣을 문구가 복사된다

### 히스토리
- `+ 모임 기록 추가` → 카드를 펼쳐 날짜·장소·참석자·사진·메모를 채운다
- 참석자는 이름을 눌러 켜고 끈다. 불참자는 자동으로 계산되어 표시된다
- `+ 안건 추가` → 제목·내용·발의자를 적고, 참석자별로 찬성/반대/기권을 누른다
- 선정 결과는 **참석자 과반 찬성이면 자동으로 「가결」**. 손으로 바꿀 수도 있다
- 사진은 나스의 `photos/연월-구분/` 폴더에 들어간다 (올릴 때 1600px 로 줄여 저장)

### 정산금 신청
- `+ 새 정산 신청` → 신청자·모임을 고르고 교통편과 부가 지출을 넣는다
- **기차 / 비행기 / 버스** → 금액 + 승차권·영수증 첨부 (필수)
- **자차** → 총 운행거리(km) + 통행료. 유류비는 `거리 ÷ 10km/L × 단가` 로 자동 계산.
  통행료를 청구하면 통행료 영수증이 필수다
- **식사·음료 등 부가 지출** → 영수증을 첨부한 건만 청구할 수 있다 (없으면 제출이 막힌다)
- `신청 제출` → 상태가 **접수**로 바뀐다
- 총무는 목록에서 **승인 → 지급완료** 로 처리한다. 반려할 때는 사유를 적는다
- `신청서 복사` → 카카오톡으로 보낼 요약문, `인쇄` → 종이 결의서

### 회칙
- `편집` 으로 조항을 고치고, 한 회의에서 바꾼 내용을 `개정 확정` 으로 한 버전으로 묶는다
- `개정 이력` 탭에서 과거 버전 전문을 보거나 그 버전으로 되돌릴 수 있다

## 4. 회원만 들어오게 막기

사이트를 밖에서도 열어 두면 주소만 아는 사람은 누구나 회비 기록과 영수증을 볼 수 있다.
아이디·비밀번호를 하나 걸고 9명에게만 알려주면 된다.

1. 브라우저에서 `http://나스주소/sagoohoe/setup-auth.php` 를 연다
2. 아이디와 비밀번호를 정해 저장한다 (둘 다 숫자만 써도 된다 — 아이디 2자리, 비밀번호 4자리부터)
3. "잠금이 걸렸습니다" 가 뜨면 끝. 시크릿 창으로 사이트를 열어 로그인 창이 뜨는지 확인한다

이렇게 하면 사이트 화면뿐 아니라 **`data/` 의 기록 파일과 `photos/` · `receipts/` 의 사진까지**
전부 로그인해야만 열린다. 주소를 직접 쳐도 막힌다.

비밀번호는 암호화(bcrypt)해서 `.htpasswd` 에 저장하므로 어디에도 원문이 남지 않는다.
바꾸려면 같은 페이지에서 새로 정하면 되고, 풀려면 같은 페이지의 "잠금 해제" 를 누른다.

> 혹시 잠금을 건 뒤 사이트 전체가 안 열리면, File Station 에서 `sagoohoe` 폴더의
> **`.htaccess`** 파일을 지우면 원래대로 돌아온다.
> (File Station 오른쪽 위 **설정 → 숨김 파일 표시** 를 켜야 보인다)

## 5. 백업

화면 맨 아래 `전체 백업 내려받기` 를 누르면 모든 자료가 JSON 한 파일로 내려온다.
모임 끝날 때마다 한 번씩 받아 두면 안전하다. `백업 불러오기` 로 되돌릴 수 있다.

나스 저장일 때는 `data/` 폴더의 JSON 파일이 원본이고, 저장할 때마다
`data/_backup/` 에 날짜별 사본이 하루 한 개씩 자동으로 남는다.

## 6. 자료가 어디에 있나

```
sagoohoe/
├── index.html          사이트 본문 (브라우저로 여는 파일)
├── api.php             나스에 자료를 읽고 쓰는 부분
├── setup-auth.php      접속 비밀번호를 거는 페이지
├── phpcheck.php        나스 상태 확인용 (문제 없으면 지워도 됨)
├── assets/             화면 코드 (css, js)
├── data/               실제 자료 — 회원·회칙·회비·모임·정산 (JSON)
│   └── _backup/        날짜별 자동 사본
├── photos/             모임 사진
└── receipts/           영수증·승차권
```

`data/` 안의 JSON 파일을 텍스트 편집기로 직접 고칠 수도 있다.
고치기 전에 그 파일을 복사해 두는 것을 권한다.

## 7. 혼자 미리 보기

PHP 없이 `index.html` 을 그냥 더블클릭해도 화면은 다 뜬다.
다만 그때는 자료가 **그 브라우저 안에만** 저장되고 사진도 브라우저 안에 들어간다.
혼자 테스트할 때만 쓰고, 실제 기록은 나스 저장으로 하는 것이 맞다.
