# 브랜드 자산 — 10분 키즈뉴스

| 파일 | 용도 | 규격 |
|---|---|---|
| `profile-1080.png` | **원본.** 실제 인스타에 올라가 있는 파일 | 1080×1080 |
| `profile.svg` | 원본을 재어 그린 벡터판. 크기를 키울 때 쓴다 | 벡터 (viewBox 1080×1080) |

PNG 이 기준이고 SVG 는 그것을 따라 그린 것이다. 픽셀 차이 0.45%(외곽선 안티앨리어싱).

## 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|

| 마스코트 이목구비 | `#e8891f` | 눈·입 (배경보다 한 톤 진하게) |
| 잉크 | `#2b2a24` | 본문 글자 |
| 네이비 | `#22304a` | 릴스 어두운 배경 |
| 크림 | `#fdf6e8` | 릴스 밝은 배경 |

## 마스코트 — 두 버전이 있다 ⚠️

| | 눈 | 비율 |
|---|---|---|
| **프로필** (`brand/`) | 주황 눈 + **흰 반짝임** | 머리가 크고 입이 아래 |
| **릴스 템플릿** (`tools/reels/*.html`) | 주황 눈만 | 머리가 작음 |

**지금 어긋나 있다.** 맞출지는 정하지 않았다.
릴스 쪽을 프로필에 맞추려면 `tools/reels/*.html` 다섯 파일의
`viewBox="0 0 64 64"` 마스코트를 모두 고쳐야 한다.

## 다시 뽑는 법

```
node <아무 스크립트>  # SVG 를 1080 뷰포트로 열어 스크린샷
```

또는 맥에서 `profile.svg` 를 브라우저로 열고 스크린샷해도 된다.
벡터라 크기는 얼마든 키울 수 있다.

## 왜 저장소에 두나

2026-11-25 에 프로필 이미지를 다시 찾으려 했는데 **어디에도 없었다.**
컨테이너 스크래치패드는 지워지고 드라이브에도 안 올려 뒀다.
릴스 템플릿 안의 마스코트 SVG 로 되살렸다. **브랜드 자산은 저장소에 둔다.**
