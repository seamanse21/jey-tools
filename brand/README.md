# 브랜드 자산 — 10분 키즈뉴스

| 파일 | 용도 | 규격 |
|---|---|---|
| `profile.svg` | 원본. 크기를 바꾸려면 이걸 쓴다 | 벡터 (viewBox 64×64) |
| `profile-1080.png` | 인스타 프로필 사진 | 1080×1080 |

## 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 브랜드 주황 | `#f08c2e` | 배경, 알약, 강조 |
| 마스코트 이목구비 | `#e8891f` | 눈·입 (배경보다 한 톤 진하게) |
| 잉크 | `#2b2a24` | 본문 글자 |
| 네이비 | `#22304a` | 릴스 어두운 배경 |
| 크림 | `#fdf6e8` | 릴스 밝은 배경 |

## 마스코트

릴스 템플릿(`tools/reels/*.html`)과 **같은 도형**이다. 한쪽만 고치지 않는다.
흰 머리 + 주황 눈·입 + 안테나 + 양옆 귀.

## 다시 뽑는 법

```
node <아무 스크립트>  # SVG 를 1080 뷰포트로 열어 스크린샷
```

또는 맥에서 `profile.svg` 를 브라우저로 열고 스크린샷해도 된다.
벡터라 크기는 얼마든 키울 수 있다.

## 왜 저장소에 두나

2026-11-25 에 프로필 이미지를 다시 찾으려 했는데 **어디에도 없었다.**
컨테이너 스크래치패드는 지워지고 드라이브에도 안 올려 뒀다.
릴스 템플릿 안의 마스코트 SVG 로 되살렸다. **브랜드 자산은 저장소에 둔다.**
