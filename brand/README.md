### ⚠️ `pointup` 과 `one` 은 같은 포즈로 나온다 (2026-11-26)
둘 다 「검지를 위로」라 이미지 모델이 구분하지 못했다. 기능도 겹친다.
**`one` 을 버리고 `hold`(지면 한 장 들어 보이기)로 바꿨다** — 실루엣이 완전히 다르고,
우리 상품이 「종이 한 장」이라 쓸 데가 더 많다.

## 배율 기준은 **발목 폭**이다 (중요)

`import-poses.py` 는 **발목선 폭**으로 크기를 맞춘다. 왜냐하면

| 기준 | 문제 |
|---|---|
| bbox 높이 | **팔 든 포즈만 작아진다** (bbox 가 커지니까) |
| `neutral` 높이 | 그 한 장이 **다른 배치**에서 오면 전부 어긋난다 |
| **발목 폭** | **포즈가 바뀌어도 다리는 그대로.** 같은 배치 안에서 값이 완전히 일치한다 |

2026-11-26 실측: 아이 5포즈 전부 `155px`, 엄마 4포즈 `81~82px`.
짝 그림에서 뽑은 `neutral` 만 `234 / 222` 로 달랐다 — **확대율이 다른 배치였다.**

목표값은 `TARGET_ANKLE = {"mom": 197, "kid": 224}`.
엄마 서 있는 키 1500px, 아이는 그 **75%**(1125px) 가 되도록 역산한 값이다.
아이 발목이 더 넓은 건 다리가 통통해서지 키가 커서가 아니다.

> **포즈를 새 배치에서 뽑으면** 발목 폭이 달라질 수 있다. 스크립트가 알아서 맞추므로
> 신경 쓸 것 없다. 다만 **같은 캐릭터의 포즈는 한 번에 몰아서 뽑는 게** 얼굴이 덜 흔들린다.

## 포즈가 이 열넷이면 충분한 이유 (2026-11-26 대본 점검)

지금까지 만든 릴스 다섯 편(NASA·김치의날·종의기원·추수감사절·블랙프라이데이)의
문장을 전부 훑어 **말의 종류**로 묶었다. 포즈는 문장 수가 아니라 **종류** 수만큼 필요하다.

| 엄마가 하는 말 | 어느 포즈로 | 대본에 몇 번 |
|---|---|---|
| 사실 선언 | `neutral` · `present` | 매 편 |
| 숫자 제시 (1620년 · 사흘 · 30% · 스물두 가지) | `pointup` + 상단 패널 | **매 편 2~4회** |
| 위 도식 짚기 | `pointup` | 매 편 |
| **대조** (손해는 붉은 / 이익은 검은, 먹이 다르면 부리도) | **`compare`** ← 없었다 | 매 편 1회 |
| 옛날 이야기 | `think` | 자주 |
| 권유·마무리 (저장해 두세요, 적어 두면) | `thumbs` | 매 편 |
| 지면 보여주기 (CTA) | **`hold`** ← 없었다 | 매 편 |

| 아이가 하는 말 | 어느 포즈로 |
|---|---|
| 질문 | `ask` |
| 갸웃 | `wonder` |
| 놀람 | `surprise` |
| 감탄 | `clap` |
| 수긍 | `nod` |
| **의심·반론** ("에이, 정말?") | **`doubt`** ← 없었다 |

### 왜 `doubt` 가 중요한가
참고 계정 분석(`기획/대화형-릴스-분석.md` 5절)에서 **시청자의 반론을 먼저 까는 것**이
이 포맷이 먹히는 세 이유 중 하나였다. 아이가 "에이, 그럼 다 똑같은 거 아니야?" 하고
끼어들면 시청자가 품은 의심이 화면에서 먼저 해소된다.
**우리 아이 포즈는 전부 긍정·중립이었다.** 의심하는 얼굴이 하나도 없었다.

### 더 안 만드는 것
- `two`·`three` 숫자 손가락 — 우리 대본은 「첫째/둘째」 구조를 안 쓴다. 숫자는 **상단 패널이 보여 준다**
- `shrug` 어깨 으쓱 — `wonder` 와 겹친다
- 걷기·앉기 — 둘 다 **서서 자리를 안 옮긴다**. 참고 계정도 그랬다

9문장짜리 릴스 한 편이 쓰는 포즈는 **아이 3~4개 · 엄마 4~5개**다. 열넷이면 남는다.

```

엄마  neutral  present  pointup  compare  hold  think  thumbs
```

얼굴은 세 배치(짝 그림 · 솔로 9장 · 다른 계정 3장)에 걸쳐 흔들리지 않았다.

### ⚠️ `present` 와 `compare` 는 거의 같게 나왔다
둘 다 양손을 펴서 바깥으로 벌린다. **릴스 크기에서는 구분이 안 된다.**
입 모양만 다르다 — `present` 는 다문 미소, `compare` 는 벌린 입(말하는 중).
**다시 뽑을 필요는 없다.** 대조는 **상단 도식 패널이 보여 주고**, 캐릭터는 「설명 중」이면 된다.
`pointup`/`one` 때와 같은 일이다 — **손 모양으로 뜻을 구분시키려 하면 이미지 모델이 못 한다.**
뜻은 자막과 패널이 지고, 캐릭터는 **감정과 방향**만 맡는다.

### 크기 기준이 두 번 바뀐 기록
| 시도 | 왜 버렸나 |
|---|---|
| `neutral` 높이 | 그 한 장이 **다른 배치**에서 오면 전부 어긋난다 |
| 발목 폭 | 포즈에는 강한데, **다른 계정 배치는 다리 굵기 비율이 달라** 키가 5~7% 작아졌다 |
| **bbox 높이 (지금)** | 대부분의 포즈에 맞다. **팔이 머리 위로 가는 포즈만** 발목 폭으로 따로 |

`ARMS_UP = {"kid": {"ask"}, "mom": {"pointup", "one"}}` — 포즈를 추가할 때
팔이 머리 위로 올라가면 **이 목록에 이름을 넣어야** 한다. 안 넣으면 그 포즈만 작아진다.
