# 포즈 10개 프롬프트 — 하나씩 그대로 복사 (2026-11-26)

`neutral` 두 장은 이미 있다. 아래 10개만 뽑으면 끝이다.

## 돌리기 전에 — 세 가지만

1. **매번 참고 이미지를 새로 붙인다.** 아이 포즈에는 `poses/kid/neutral.png`,
   엄마 포즈에는 `poses/mom/neutral.png`. **직전에 만든 포즈를 참고로 쓰지 않는다** —
   한 장씩 멀어지면서 얼굴이 조금씩 달라진다. 항상 `neutral` 한 장만 기준으로 쓴다.
2. **한 번에 하나씩.** 여러 포즈를 한 번에 시키면 얼굴이 섞인다.
3. **배경은 흰색으로 시킨다.** 「투명」을 시키면 모델이 체크무늬를 그려 버린다
   (2026-11-26 에 겪었다). 흰 배경이면 `import-poses.py` 가 깨끗이 떼어 낸다.

파일 이름은 각 프롬프트 제목의 영어 단어 그대로.
→ `poses/_raw/kid/ask.png` · `poses/_raw/mom/think.png` …

# 다 받으면

```bash
cd 저장소/jey-tools/brand && python3 import-poses.py
```

배경 제거 · 크기 통일 · 발바닥 정렬을 한 번에 한다.
끝나면 **키 비율**을 찍어 준다 — 60~80% 면 「엄마와 아이」로 읽힌다.

## 잘 안 나올 때
| 증상 | 손볼 곳 |
|---|---|
| 얼굴이 달라졌다 | 참고 이미지를 **`neutral` 로** 다시. 직전 포즈를 쓰면 점점 멀어진다 |
| 팔이 얼굴을 가린다 | `up and outward to the side` 를 **한 번 더** 강조해서 다시 |
| 크기가 제각각 | 괜찮다. 스크립트가 `neutral` 기준으로 맞춘다 |
| 배경이 체크무늬 | 괜찮다. 스크립트가 떼어 낸다 |
| 외곽선이 생겼다 | `no outlines` 를 맨 앞으로 옮겨서 다시 |
