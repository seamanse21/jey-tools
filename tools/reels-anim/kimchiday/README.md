## 자체 검수에서 고친 것 (`qa-checklist.md`)

1. **16초 — 점선 칸만 있고 허전함.** 칸을 304→418px 로 키우고
   라벨을 회색으로 먼저 깔았다가 타일이 꽂힐 때 검게 바꿈.
2. **30초 — 배양접시가 비어 있음.** 미생물 점 등장을 `W(6,8)` → `W(6,2)` 로 당김.
3. **50초 — 아래쪽이 빔.** 카드 두 장을 내리고 키움(1180~1630px), 두 번째를 한 단어 앞당김.

## 올릴 때

- **소리가 영상에 들어 있다.** 인스타 음원을 따로 얹지 않아도 되고,
  그래서 **PC 에서 올려도 된다.** (A안은 음원 때문에 모바일이어야 했다.)
- **프레임 0 이 비어 있다.** anim-reel 은 `lead` 0.4초를 두고 시작한다.
  그쪽 규칙이라 고치지 않았다. **커버를 직접 골라야 한다.**
- AI 목소리를 썼으므로 업로드할 때 **"AI 정보" 라벨**을 켜는 게 안전하다.
- CTA 가 "댓글에 김치" 다. **댓글에 답을 보내 줘야 말이 된다.**
  자동 DM 도구가 없으면 직접 보내야 한다.
