# B안 — anim-reel 릴스 (맥에서 만든 것)

> **아직 비어 있다.** 맥에 설치한 `anim-reel` 의 규칙 파일을 받으면 여기에 옮긴다.
> A안(자체 템플릿) 규칙은 `../reels/NOTES.md` 에 있다. **서로 덮지 않는다.**

## 왜 분리하나

2026-11-18 기준 릴스 1번 게시물이 평균 조회 시간 1초 · 건너뛰기 90.9% 로 나왔다.
A안 훅을 고쳐서 다시 재는 중인데, 같은 시기에 맥에서 `anim-reel` 로
같은 주제(김치의 날)를 만든 결과물이 생겼다.

**둘을 같은 주제로 나란히 올려 숫자로 고른다.** 감으로 고르지 않는다.
그래서 규칙을 합치거나 덮지 않고 끝까지 따로 둔다.

## 현재 상태 — 2026-11-18

| 확인한 것 | 결과 |
|---|---|
| 이 컨테이너에 `anim-reel` 설치 여부 | **없음** (저장소 · 플러그인 · 스킬 · npm 전역 전부) |
| 플러그인 카탈로그에 `anim-reel` | **없음** |
| 맥 Remote Control 연결 | **불가.** 목록에 맥이 없다 (`이정문-연구동-PC` 만 있고 그 폴더도 제공 안 됨) |

→ **지금 상태로는 여기서 B안을 재현할 수 없다.** 규칙 파일이 필요하다.

## 받아야 할 것 세 가지

1. **`anim-reel` 자체** — SKILL.md, 템플릿, 렌더 스크립트. 규칙을 알아야 재현한다.
2. **김치의 날 결과물 mp4** — A안 `11-20_금_김치의날.mp4` 와 나란히 비교할 원본.
3. **그때 넣은 입력** — 프롬프트나 데이터 파일. 같은 입력으로 다시 돌려 봐야 한다.

## 재현할 때 확인할 것

받고 나면 이 네 가지부터 맞춘다. A안과 조건을 똑같이 맞춰야 비교가 성립한다.

- 규격이 1080×1920 · 30fps · H.264 인가
- 길이가 20초인가 (A안 표준)
- **프레임 0 에 텍스트가 꽉 차 있는가** — 자동 썸네일이 여기서 결정된다
- 폰트가 컨테이너에 있는 것만 쓰는가 (`tools/fonts/` 183종)
