# 한자 급수 퀴즈 — 작업 메모

원본: Claude 아티팩트 "한자 급수 퀴즈" (version 1788072111-0a0d) → 이 저장소로 이관.

## 현재 사양
- 8급~1급 급수별 한자 퀴즈. 4급 이상에는 사자성어가 섞여 있고 카테고리(전체/한자/사자성어)로 걸러 볼 수 있음
- 한자를 보여주고 화면을 터치하면 훈음(사자성어는 독음+뜻풀이)이 나옴
- 훈음 읽어주기 — 브라우저 내장 `speechSynthesis`(ko-KR) 사용. 외부 API·네트워크 불필요
- 점수판: 참가자를 추가해 여러 명이 같이 할 수 있음
- 급수·카테고리·점수는 localStorage(`hanjaquiz_state_v1`)에 저장

## 이관하면서 바꾼 것
- 아티팩트 껍데기(바깥 html/head/body)를 벗기고 안쪽 문서만 남김
- 좌측 하단에 `← Jey Tools` 링크 추가 (`.jey-back`)
- 그 외 내용은 원본 그대로. 외부 의존이 전혀 없는 단일 HTML

## 데이터
- `WORD_DATA` 상수에 급수별 배열. `type`은 `hanja`(en=한자, ko=훈음) 또는 `idiom`(en=사자성어, ipa=독음, ko=뜻풀이)
- 한국어문회 공식 배정한자 전체가 아니라 급수별 난이도에 맞춘 학습용 축약 세트.
  항목을 늘리려면 해당 급수 배열에 같은 형식으로 추가하면 된다

## 검증 (2026-11-03, 헤드리스 크롬)
- 8급 진입 → 카드 터치 → 훈음 표시 정상 (예: 小 → "작을 소")
- 4급으로 전환 시 카테고리 메뉴에 전체/한자/사자성어 생성 확인
- 다음 한자 버튼, 점수판 참가자 2명, 목록 왕복 이동 정상
- 콘솔 오류 없음
