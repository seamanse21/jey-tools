# 하루한장 키즈신문 — 작업 메모

## 무엇을 하는 도구인가
하루 한 장짜리 어린이 신문을 만들어 **A4 한 장으로 인쇄**한다.
부모가 기사를 고르거나 직접 써 넣고, 그림칸·생각거리·한 줄 쓰기 칸은 아이가 종이에 직접 채운다.

## 현재 사양
- 신문 머리: 신문 이름, 기자 이름, 날짜(요일 자동), 제N호, 날씨
- 머리기사: 제목 + 본문 + 사진(선택) 또는 그림 그리는 칸
- 작은 기사 2개, 오늘의 낱말(낱말+뜻), 생각해 보기 2문항 + 쓰는 줄, 아래쪽 한 줄 쓰기 칸
- **소재 모음 31개** — `BANK` 상수. 항목마다 제목·본문(4문장)·낱말·뜻·질문 2개.
  [머리] 누르면 머리기사+낱말+질문까지 한 번에, [작은] 누르면 앞 두 문장만 잘라 작은 기사 칸에 들어간다
- 본문 글자 크기 9~14pt 조절. 내용이 한 장을 넘으면 상단에 경고가 뜬다(`checkOverflow`)
- 머리기사 읽어주기 — 브라우저 내장 `speechSynthesis`(ko-KR)
- 보관함: 호별로 localStorage에 저장·불러오기·삭제. 편집 중 내용은 자동 임시저장
- 외부 라이브러리·API·네트워크 없음. 파일 하나로 완결

## 구현 메모
- 종이는 `210mm × 297mm` 고정 `.paper`. 화면에서는 `transform: scale()` 로 줄여 보여 주고(`fit()`),
  인쇄할 때는 `@media print` 에서 `transform:none` 으로 되돌려 1:1 로 찍는다. `@page { size:A4; margin:0 }`
- 본문 글자 크기는 `.paper` 의 CSS 변수 `--fs` 하나로 조절. 작은 기사는 `--fs - 1pt`
- 넘침 판정은 `scrollHeight > clientHeight` 비교. `.flow` 에 `overflow:hidden` 이 걸려 있어
  넘친 글자는 인쇄에 안 나오므로, 경고가 뜨면 글자 크기를 줄이거나 문장을 덜어야 한다
- 사진은 `FileReader` → canvas 로 가로 1100px/JPEG 0.82 로 줄여 dataURL 로 보관(localStorage 용량 때문).
  파일은 브라우저 밖으로 나가지 않는다
- 저장 키: `kidsnews_draft_v1`(편집 중), `kidsnews_issues_v1`(보관함)
- 글꼴은 시스템 글꼴만 쓴다. 제호·제목은 명조 계열(AppleMyungjo/Batang), 본문은 고딕

## 소재를 더 넣으려면
`BANK` 배열에 `{t, b, w, m, q1, q2}` 형식으로 추가하면 목록·검색에 바로 잡힌다.
초등 저학년이 읽을 수 있게 본문은 4문장 안팎, 숫자는 확인된 것만 쓴다.

## 검증 (2026-11-16, 헤드리스 크롬)
- 첫 화면에서 꿀벌(머리) + 나이테·무지개(작은)로 한 장이 채워져 보임, 콘솔 오류 0건
- 소재 [머리] 클릭 → 제목·본문·낱말·질문 동시 교체 확인
- 넘침 경고: 기본 내용에서 네 영역 모두 여유 있음(over 0)
- `page.pdf(A4)` 출력 결과 **1쪽**으로 떨어지는 것 확인
