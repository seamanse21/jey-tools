# 한국사 기출 퀴즈 — 작업 메모

한국사능력검정시험 기출 PDF를 문항별로 잘라 4지선다 퀴즈로 바꾸는 도구. 2026-11-08 제작.

## 왜 이런 구조인가
기출 문제는 **저작권**과 **용량**이 둘 다 걸린다. 79회 기본 문제지가 22MB다.
그래서 문제를 저장소에 넣지 않고, **사용자가 공식 사이트에서 받은 PDF를 브라우저 안에서 변환**한다.
저장소에는 문제 이미지가 한 장도 없고, 서버로 전송되는 것도 없다.

## 79회 기본 PDF 분석 결과 (설계 근거)
- **문제지**: 12쪽, 22MB, 텍스트 레이어 **0자**, 글꼴 **0개** → 글자가 전부 윤곽선으로 변환돼 있다.
  문항 번호를 읽어 자동 분할하는 길이 막혀 있다
- **정답표**: 텍스트 레이어 정상 → 그대로 파싱된다
- 레이아웃: 2단, 쪽당 4~5문항, 문항 높이 제각각 (격자 분할 불가)

## 자동 분할 방식
1. 각 쪽을 110dpi 로 렌더
2. **세로 구분선**: 가운데 42~58% 중 잉크가 가장 긴 열 (1004px 중 888px, 전 쪽 성공)
3. **머리말 끝**: 위 25% 안에서 폭 70% 이상을 가로지르는 마지막 가로줄
   (1쪽은 제목 아래 굵은 선 0.142, 2쪽부터는 머리말 띠 아래 0.059 — 자동으로 구분됨)
4. 각 단에서 가로 잉크 투영 → 빈 줄이 길게 이어지는 곳을 경계 후보로 (일부러 과분할)
5. **목표 개수(50)까지 틈이 작은 쌍부터 병합**
6. `seal()` 로 구간을 **빈틈없이 맞붙인다** — 이걸 안 하면 문항 사이 여백에 걸친
   질문 문장이 어느 구간에도 안 들어가 누락된다 (실제로 1번에서 발생했던 버그)
7. 자를 때는 구간 안에서 **실제 잉크 범위로 좁힌다** — 커버리지는 6번이 보장하므로 안전

### 한계
총 개수는 정확히 50으로 맞지만 **경계가 몇 개는 틀린다.**
79회 기준 쪽별 `[4,5,5,4,4,4,4,4,4,4,4,4]` 인데 실제 2쪽은 4문항이다 (1개 과분할).
완전 자동은 불가능하므로 **편집기에서 손보는 것을 전제**로 설계했다.
- 선 끌기 = 경계 이동 / 선 두 번 누르기 = 위아래 합치기 / 빈 곳 누르기 = 경계 추가
- `단 단위로` 버튼: 분할을 포기하고 반쪽씩 본다. 구분선 검출은 100% 성공하므로 오류가 없다

## 정답표 파싱
`①②③④` 기호를 찾고 **직전 3토큰 안의 1~50 숫자**를 문항 번호로 본다.
79회 기본 50문항 전부 정확히 읽었다 (수동 확인한 값과 일치).

## 저장
- `localStorage` `hxquiz.v1` — 시험지 목록, 정답, 문항별 풀이 기록
- `IndexedDB` `hxquiz/crops` — 문항 이미지(JPEG). 키는 `<시험지id>#<문항index>`
- PDF 원본은 보관하지 않는다. 잘라낸 문항 이미지만 남으므로 재생이 빠르고 가볍다

## 외부 의존
PDF.js 3.11.174(Apache-2.0)를 **HTML 안에 내장**했다. 파일이 1.5MB로 커졌지만
다른 도구와 같은 원칙(단일 파일·CDN 없음·오프라인 동작)을 지킨다.
- 본체는 `<script>` 로, 워커는 `<script type="text/plain" id="pdfworker">` 로 넣고
  런타임에 Blob URL 로 만들어 `workerSrc` 에 넘긴다 (두 파일 모두 `</script` 미포함 확인)
- 갱신: `npm pack pdfjs-dist` → `legacy/build/pdf.min.js`, `pdf.worker.min.js`

## 검증 (2026-11-08, 헤드리스 크롬 · 79회 기본 실파일)
- 12쪽 렌더 → 자동 분할 **50문항**, 쪽별 `[4,5,5,4,4,4,4,4,4,4,4,4]`
- 정답표 자동 인식 **50/50**, 문자열 `4324213221 4312441213 4411343112 2123111333 4134434442`
- 1~6번 잘린 이미지 눈으로 확인 — 질문·자료·선택지 모두 온전
- 저장 후 풀기: 1번 ④ 정답 / 2번 ① 오답(정답 ③) — 정답표와 일치, 정답률·오답 수 갱신 정상
- 콘솔 오류 없음
