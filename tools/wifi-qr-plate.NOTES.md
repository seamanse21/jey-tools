# 와이파이 QR 액자 — 작업 메모

원본: Claude 대화 아티팩트 "와이파이 QR 액자" (2026-11-03) → 이 저장소로 이관.

## 현재 사양
- 입력: SSID / 비밀번호 / 보안방식(WPA·WEP·없음) / 숨김 네트워크 → `WIFI:T:..;S:..;P:..;H:true;;` 문자열
- 명판: 가로 60~180mm, 바닥판 두께 1.6~5mm, QR 돌출 0.4~2mm
- 옵션: 액자 테두리(2.4mm), 상단 걸이 구멍 3개(Ø5, 좌=8mm·중앙·우=W-8mm, 상단 여유 12mm), QR 가운데 Wi-Fi 부채꼴 아이콘, 하단 안내 문구 2줄
  (1줄은 직접 입력, 2줄은 `Wi-Fi : <SSID>` 형식으로 자동 생성)
- 아이콘을 넣으면 QR 오류정정 등급이 자동으로 H로 올라감(약 30% 손상까지 복구)
- 출력물: zip 안에 `wifi_plate_all.stl` / `_base.stl` / `_relief.stl` 3개. QR 이미지 PNG 따로 저장 가능
- QR 한 칸이 2mm 미만이면 통계 칸이 경고로 바뀜

## 구현 메모
- QR 생성: qrcode-generator 1.4.4 (CDN)
- 글자·아이콘은 캔버스에 래스터라이즈 후 가로 런(run)을 사각형으로 묶어 돌출 박스로 변환
- 걸이 구멍은 `holeCell()` 이 사각 셀 + 원형 관통으로 측벽까지 만들어 매니폴드 유지
- STL은 바이너리, Y축을 뒤집어(`H - y`) 프린터 좌표로 변환
- zip은 무압축(store) 방식으로 직접 생성
- 아티팩트 버전은 `claude.use("downloads")` 를 썼지만, 이 저장소 버전은 일반 브라우저 다운로드(`saveBlob`)로 교체함
- qrcode-generator 1.4.4(MIT)를 CDN 대신 HTML 안에 통째로 넣음 → 인터넷 없이도 동작.
  갱신하려면 `npm pack qrcode-generator` 로 받은 `package/qrcode.js` 내용으로 HTML 안의 `<!-- QR 생성 라이브러리 내장 -->` 블록을 교체
- 글꼴만 Google Fonts에서 불러옴. 오프라인이면 시스템 글꼴로 자동 대체되고 기능에는 영향 없음

## 검증 (2026-11-03, 헤드리스 크롬)
- SSID `JEY_HOME_5G` / 비밀번호 `p@ss;word,test` 입력 → 생성된 QR을 jsQR로 디코딩
  결과 `WIFI:T:WPA;S:JEY_HOME_5G;P:p@ss\;word\,test;;` — 세미콜론·쉼표 이스케이프 정상
- zip 3개 STL 모두 바이너리 헤더·삼각형 수 일치, 치수 100×129mm / 바닥판 0~2.4mm / 돌출 2.4~3.2mm 확인
- 콘솔 오류 없음, 390px 폭에서도 레이아웃 정상
