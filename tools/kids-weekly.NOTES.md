# 주간 키즈신문 발행기 — 작업 메모

## 왜 만들었나
휘민이가 보던 구독형 어린이 신문(매달 평일 20일치 PDF)의 **구성 패턴**을 이어서,
직접 주 단위(월~금 5일치)로 발행하려고 만든 도구.

> 원본 PDF는 저작권 보호 문구가 명시돼 있다. 캐릭터·제호·문구·그림은 **복제하지 않았고**,
> 하루치를 `기사면 + 활동지면` 두 장으로 구성하는 **형식만** 참고했다. 마스코트(부엉이 SVG)·
> 제호·안내 문구는 모두 이 도구에서 새로 만든 것이다.

## 한 호의 구성 (A4 12쪽)
1. 표지 — 신문 이름, 호수, 그 주 기사 목록
2. 보호자 안내 — 학년별 활용법, 이번 주 기사·낱말 표, 대화 가이드
3~12. 하루치 ×5 — **기사면**(상단 띠 → 제호 → 사진 자리 → 부제·제목 → 2단 본문 →
   오늘의 단어 → 같이 해보자 → 낱말 메모 줄) + **활동지면**(질문1 + 질문2 + 쓰는 줄)

## 기능
- 요일 탭으로 5일치를 각각 편집. 분류는 기념일·인물·사회·과학·문화·마음
- 본문에서 `*별표*`로 감싼 낱말은 기사에 색으로 강조된다(오늘의 단어와 연결)
- 활동지 질문1 모양 4가지: `cards`(보기 4개 중 고르기) / `write`(쓰는 상자 2개) /
  `draw`(그림 + 설명) / `lines`(줄만)
- **소재 찾기** — `BANK` 38개. 발행 주에 걸린 기념일·인물·사건을 맨 위에 `이번 주` 배지로 올려 준다.
  [넣기]를 누르면 제목·부제·초안 본문·낱말·질문이 한 번에 들어간다
- **글자 크기 자동 맞춤** — 기사별로 9~11.4pt 사이에서 한 쪽을 넘지 않는 최대값을 찾아 적용
- **원고 주고받기** — [원고 요청문 복사]로 주문서를 만들어 클로드에 붙여넣고,
  받은 JSON을 [불러오기]로 밀어 넣으면 5일치가 한 번에 채워진다. 현재 호 JSON 내보내기도 가능
- 사진은 가로 1200px / JPEG 0.82로 줄여 브라우저 안에만 저장. 외부로 나가지 않는다
- 보관함(localStorage): 호별 저장·불러오기·삭제. 편집 중 내용은 자동 임시저장
- 인쇄: 전체 12쪽, 또는 선택한 하루치 2쪽만

## 매주 발행하는 흐름
1. 그 주 월요일 날짜를 넣고 [원고 요청문 복사]
2. 클로드에 붙여넣어 5일치 JSON 받기 (소재가 정해져 있으면 요청문에 덧붙이면 된다)
3. JSON을 붙여넣고 [불러오기] → [글자 크기 자동 맞춤] → [전체 인쇄]
4. 보관함에 저장

소재를 직접 고르고 싶으면 2번 대신 **소재 찾기**에서 [넣기] 하고 본문만 다듬어도 된다.

## 구현 메모
- 지면은 `210mm × 297mm` 고정 `.page` 12장. 화면에서는 `transform: scale()`(`fit()`),
  인쇄에서는 `transform:none` 으로 1:1 (`@page { size:A4; margin:0 }`)
- 화면에 안 보이는 쪽은 래퍼에 `.off`(화면 전용 숨김). 하루치만 인쇄할 때는 `.skip`을 쓴다.
  `display:none`을 인라인으로 주면 인쇄에서도 사라지므로 반드시 클래스로 처리할 것
- 본문은 CSS `columns:2`. 넘침 판정은 `.cols` 의 `scrollHeight > clientHeight`
  (`.cols` 는 `overflow:hidden` 이라 넘친 글자는 인쇄되지 않는다 → 경고가 뜨면 반드시 줄여야 함)
- 글꼴은 시스템 글꼴만. 외부 라이브러리·API·네트워크 없이 HTML 한 파일로 동작
- 저장 키: `kidsweekly_draft_v1`, `kidsweekly_issues_v1`

## 소재를 더 넣으려면
`BANK` 에 `{md, cat, t, k, w, m, ex, q1, q2, s}` 형식으로 추가한다.
`md` 는 `"11-17"` 처럼 월-일(상시 소재는 빈 문자열), `s` 는 3문장 정도의 초안 본문.

- 기본 상태에서 12쪽 생성, 콘솔 오류 0건, `page.pdf(A4)` 결과 **12쪽**
- 자동 맞춤 후 5개 기사면 모두 넘침 0
- 활동지 4가지 모양(cards/write/draw/lines) 렌더 확인
- JSON 붙여넣기 → 5일치 재구성 및 재렌더 확인
