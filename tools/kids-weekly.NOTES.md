# 주간 키즈신문 발행기 — 작업 메모

## 왜 만들었나
휘민이가 보던 구독형 어린이 신문(매달 평일 20일치 PDF)의 **구성 패턴**을 이어서,
직접 주 단위(월~금 5일치)로 발행하려고 만든 도구.

> 원본 PDF는 저작권 보호 문구가 명시돼 있다. 캐릭터·제호·문구·그림은 **복제하지 않았고**,
> 하루치를 `기사면 + 활동지면` 두 장으로 구성하는 **형식만** 참고했다. 마스코트(부엉이 SVG)·
> 제호·안내 문구는 모두 이 도구에서 새로 만든 것이다.

## 한 호의 구성 (A4 12쪽)
1. 표지 — 신문 이름, 호수, 그 주 기사 목록
2. 보호자 안내 — 학년별 활용법, 이번 주 기사·낱말 표, 대화 가이드
3~12. 하루치 ×5 — **기사면**(상단 띠 → 제호 → 사진 자리 → 부제·제목 → 2단 본문 →
   오늘의 단어 → 같이 해보자 → 낱말 메모 줄) + **활동지면**

활동지면은 **쓰기보다 보는 재미**가 목적이다(2026-11-16 방향 수정).
1. 내용 확인 — O/X 세 문항. 동그라미만 치면 된다 (2026-11-18 "맞혀 보기" 에서 이름 바꿈)
2. **오늘의 어휘** — 오늘의 사자성어(한자 넉 자·독음·뜻·쓰임새) + 오늘의 한자(훈음·급수·획수·따라쓰기 칸)
3. 낱말 채우기 — 오늘의 단어를 넣는 빈칸 문장 하나
4. (선택) 추가 활동 — 그리기 / 고르기 / 쓰는 칸. 기본값은 '없음'
5. 더 알아보기 — 기사에 안 나온 곁가지 상식 두세 개
6. 한 줄 쓰기 — 질문을 비우면 칸 자체가 사라진다
- 정답은 지면 맨 아래에 **거꾸로** 인쇄된다(종이를 돌려 확인)
- 추가 활동이 있는 날은 자동으로 상식을 2개로 줄이고 한 줄 쓰기를 뺀다 — 한 쪽을 넘기지 않기 위해서다

기사면 사이드바 맨 아래에는 **오늘의 읽기**(별점·읽은 시간·소리내어/혼자 체크)가 매일 들어간다.
읽기 습관을 눈에 보이게 하는 장치이자, 비어 보이던 사이드바를 채우는 역할이다.

## 기능
- 요일 탭으로 5일치를 각각 편집. 분류는 기념일·인물·사회·과학·문화·마음
- 본문에서 `*별표*`로 감싼 낱말은 기사에 색으로 강조된다(오늘의 단어와 연결)
- 활동지 데이터는 모두 **줄 단위 텍스트**다. `quiz`는 `문장 | O`, `fill`은 `문장 ___ | 정답`,
  `facts`는 `제목 | 내용`. 파싱은 `rows()` 하나로 처리한다
- `idiom`은 `한자 | 독음 | 뜻 | 쓰임새`, `hanja`는 `한자 | 훈음 | 급수 | 획수 | 활용 낱말`.
  이 둘은 칸이 네다섯이라 `rows()` 대신 `parts()`(그냥 `|` 로 자르기)로 읽는다
- 분류마다 색이 정해져 있다(`CAT_COLOR`). 페이지에 `--cat` 으로 꽂아 제목·뱃지·테두리·강조어에 함께 쓴다
- 추가 활동 `type`: `none`(기본) / `cards` / `draw` / `write`
- **소재 찾기** — `BANK` 38개. 발행 주에 걸린 기념일·인물·사건을 맨 위에 `이번 주` 배지로 올려 준다.
  [넣기]를 누르면 제목·부제·초안 본문·낱말·질문이 한 번에 들어간다
- **글자 크기 자동 맞춤** — 기사별로 9~11.4pt 사이에서 한 쪽을 넘지 않는 최대값을 찾아 적용
- **원고 주고받기** — [원고 요청문 복사]로 주문서를 만들어 클로드에 붙여넣고,
  받은 JSON을 [불러오기]로 밀어 넣으면 5일치가 한 번에 채워진다. 현재 호 JSON 내보내기도 가능
- 사진은 가로 1200px / JPEG 0.82로 줄여 브라우저 안에만 저장. 외부로 나가지 않는다
- 보관함(localStorage): 호별 저장·불러오기·삭제. 편집 중 내용은 자동 임시저장
- 인쇄: 전체 12쪽, 또는 선택한 하루치 2쪽만

## 매주 발행하는 흐름 (자동)
매주 금요일 19:49(KST)에 예약 작업 `trig_0119e9hLQ4rsaqNTvVGVm9sz` 이 다음 주 5일치를 만들어
`tools/issues/<월요일>.json` 으로 커밋하고 `tools/issues/index.json` 에 한 줄 추가한다.

받아 쓰는 쪽은 세 단계다.
1. 발행기를 연다 (GitHub Pages 주소로 열어야 목록을 가져온다)
2. `주간 원고 주고받기` → [📂 저장된 호 불러오기] → 원하는 주간의 [열기]
3. [글자 크기 자동 맞춤] → [전체 인쇄]

직접 만들고 싶을 때는 [원고 요청문 복사]로 주문서를 받아 클로드에 넣고, 돌아온 JSON을 붙여넣으면 된다.
소재만 고르고 본문을 직접 쓰려면 **소재 찾기**에서 [넣기] 한 뒤 다듬는다.

## 호 저장 형식
- `tools/issues/<월요일 YYYY-MM-DD>.json` — 발행기가 그대로 읽는 한 호의 원고
- `tools/issues/index.json` — `{updated, issues:[{week,end,issue,file,published,heads,cats}]}`
  발행기의 [저장된 호 불러오기]가 이 파일을 읽어 목록을 만든다. 새 호를 넣을 때 기존 항목을 지우면 안 된다.
- 노션(🔁 루틴 / 📰 키즈신문)은 입구 역할만 한다. 주차별 기록은 저장소에만 쌓인다.

## 구현 메모
- 지면은 `210mm × 297mm` 고정 `.page` 12장. 화면에서는 `transform: scale()`(`fit()`),
  인쇄에서는 `transform:none` 으로 1:1 (`@page { size:A4; margin:0 }`)
- 화면에 안 보이는 쪽은 래퍼에 `.off`(화면 전용 숨김). 하루치만 인쇄할 때는 `.skip`을 쓴다.
  `display:none`을 인라인으로 주면 인쇄에서도 사라지므로 반드시 클래스로 처리할 것
- 본문은 CSS `columns:2`. 넘침 판정은 `.cols` 의 `scrollHeight > clientHeight`
  (`.cols` 는 `overflow:hidden` 이라 넘친 글자는 인쇄되지 않는다 → 경고가 뜨면 반드시 줄여야 함)
- 글꼴은 시스템 글꼴만. 외부 라이브러리·API·네트워크 없이 HTML 한 파일로 동작
- 저장 키: `kidsweekly_draft_v1`, `kidsweekly_issues_v1`
- [저장된 호 불러오기]는 `fetch("./issues/index.json")` 이라 **file:// 로 연 경우에는 동작하지 않는다**.
  그때는 안내 문구를 띄우고 붙여넣기 칸을 쓰게 한다. 나머지 기능은 오프라인에서 그대로 동작한다

## 소재를 더 넣으려면
`BANK` 에 `{md, cat, t, k, w, m, ex, q1, q2, s}` 형식으로 추가한다.
`md` 는 `"11-17"` 처럼 월-일(상시 소재는 빈 문자열), `s` 는 3문장 정도의 초안 본문.

## 용량 (2026-11-16 실측, 헤드리스 크롬 PDF 출력)
- 사진 없는 12쪽 — 약 **620KB** (대부분 한글 글꼴 임베딩)
- 사진 5장(가로 1200px JPEG) 넣은 12쪽 — 약 **760KB**
- 도구 파일 자체 76KB
즉 **한 주치가 1MB 안쪽**. 구독하던 월간 PDF가 80MB였던 것은 쪽마다 고해상도 사진·일러스트가
들어갔기 때문이고, 이 도구는 쪽당 50~60KB 수준이다.

## 검증 (2026-11-16, 헤드리스 크롬)
- 기본 상태에서 12쪽 생성, 콘솔 오류 0건, `page.pdf(A4)` 결과 **12쪽**
- 자동 맞춤 후 5개 기사면 모두 넘침 0
- 활동지 개편본(퀴즈 + 빈칸 + 더 알아보기 + 한 줄) 렌더 확인, 추가 활동 draw 포함
- 예전 형식으로 저장된 호는 `migrate()` 로 새 형식에 맞춰 열린다
- JSON 붙여넣기 → 5일치 재구성 및 재렌더 확인
