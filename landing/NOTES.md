## 폼 연결 (완료)
스티비 주소록 `530755` 의 구독 폼을 붙였다. 마크업·id·클래스는 스티비가 만들어 준 것을
그대로 쓰고, **스티비 CSS(`stb_subscribe_form_style.css`)는 일부러 불러오지 않는다.**
`.stb_*` 클래스는 `index.html` 안에서 직접 스타일을 준다. 그래야 우리 디자인이 유지된다.

필드: `email` / `grade`(아이 학년) / `stb_policy` / `stb_ad_agreement`

### 스티비 기본 코드의 버그 세 가지를 고쳐 뒀다
그대로 붙여 넣으면 콘솔 오류가 난다. 폼 코드를 다시 받아 교체할 때 같은 수정을 다시 해야 한다.

1. 첫 동의 항목의 버튼 id 가 `stb_form_modal_open` / `stb_form_modal_close` 인데,
   스크립트의 구버전 선택자(`#stb_form_modal_open`)와 겹쳐 `openModalOld` 가 같이 실행된다.
   그 함수는 없는 `#stb_form_modal` 을 찾아 null 을 참조한다.
   → id 를 `stb_policy_modal_open` / `stb_policy_modal_close` 로 바꿨다
2. `id="stb_form_modal_bg"` 가 두 번 나와 중복이다 → 광고 모달 쪽 id 를 뺐다
3. 스티비 `closeModal` 은 `e.target.dataset.modal` 을 읽는데 배경 div 에 그 속성이 없다
   → 배경 div 에 `data-modal` 을 넣었다. 배경 클릭·Esc 로 닫는 핸들러도 따로 달았다

### 광고성 정보 수신 동의는 (선택)이다
처음에 (필수)로 만들었는데 잘못이었다. 선택 동의를 하지 않았다는 이유로 서비스 제공을
거부할 수 없다. 대신 체크박스 아래에 "매주 무료 1장을 받으시려면 체크해 주세요" 를 적었다.
개인정보 수집·이용 동의만 (필수)다.

### 자동 응답은 '구독 확인 이메일' 로 대신한다
스티비 무료 요금제에는 가입 즉시 발송이 없을 수 있다. 구독 확인 이메일은 무료에서도 되므로
그 본문에 PDF 다운로드 링크를 넣는다. PDF 를 받으려면 확인 링크를 눌러야 하니
더블 옵트인의 이탈 문제도 같이 풀린다.

## 아이 학년을 받는 이유
칸이 하나 느는 마찰보다 얻는 게 크다. 학년별 발송이 가능해지고,
물어보는 행위 자체가 "내 아이를 위한 것"이라는 신호가 되어 전환이 오히려 오른다.
