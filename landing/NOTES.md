# 10분 키즈뉴스 랜딩 페이지 — 작업 메모

## 무엇인가
무료 샘플(1주치 14쪽 PDF)을 미끼로 이메일을 모으는 한 장짜리 랜딩.
인스타 프로필 링크의 도착지다. 설계 근거는 `docs/landing-strategy.md`, 퍼널 전체는 `docs/funnel.md`.

## 구조 — 쇼윈도 게이트
lazyowen.com 은 글의 뒷부분을 가리지만, 우리 상품은 PDF 라서 가릴 본문이 없다.
그래서 **품질은 다 보여주고 파일만 가둔다**.

1. 히어로 — 월요일 기사면을 실물 그대로 공개(눌러서 확대)
2. 공감 — "스마트폰 말고 뭘 시키지?"
3. 특징 3개 — 하루 10분 / 매일 같은 자리 / 주말 복습
4. 지면 두 장 — 기사면 + 활동지면
5. 1주일치 구성 14쪽 표
6. **게이트** — 이메일 + 아이 학년 + 동의 2개
7. FAQ 5개

## 폼 연결 (아직 안 됨)
`index.html` 의 `<!-- ▼ 스티비 폼 연결 지점 -->` 사이가 교체 대상이다.
스티비에서 구독 폼을 만든 뒤 `<form>` 의 `action` 과 각 `name` 을 스티비 값으로 바꾸면 된다.
현재는 `action` 이 비어 있어 제출하면 안내 알림만 뜬다.

필드: `email` / `grade`(아이 학년) / `consent_privacy` / `consent_ads`

> 동의 체크박스 2개는 **반드시 분리**해야 한다(정보통신망법).
> 광고성 정보 수신 동의 없이 홍보 메일을 보내면 안 된다.

## 아이 학년을 받는 이유
칸이 하나 느는 마찰보다 얻는 게 크다. 학년별 발송이 가능해지고,
물어보는 행위 자체가 "내 아이를 위한 것"이라는 신호가 되어 전환이 오히려 오른다.

## 파일
- `index.html` — 전부. 외부 라이브러리·스크립트 없음
- `fonts.css` + `fonts/` — Jua(제목) · Gowun Dodum(본문). 구글 폰트 OFL 자체 호스팅.
  **`fonts.css` 는 반드시 `landing/` 바로 아래 둔다.** 안의 경로가 `./fonts/...` 라서
  `fonts/` 안으로 옮기면 전부 404 가 나고 시스템 글꼴로 조용히 바뀐다(한 번 겪음)
- `img/` — 발행기에서 뽑아 1100px·JPEG 84 로 줄인 지면 이미지

## 이미지 다시 만들기
발행기(`tools/kids-weekly.html`)를 띄우고 호를 불러온 뒤 지면을 캡처해
1100px 폭 JPEG 로 저장한다. 원본 PNG 그대로 쓰면 400KB 가 넘는다.
